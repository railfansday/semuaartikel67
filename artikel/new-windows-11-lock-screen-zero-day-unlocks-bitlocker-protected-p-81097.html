New Windows 11 lock screen zero-day unlocks BitLocker-protected PCs with just a few keystrokes

Considering the current status of the cybersecurity landscape, some may well say that "0-day" has lost its meaning, The latest high-stakes vulnerability pertains to a bug in Windows 11 (and possibly 10), wherein an attacker can partially bypass the lock screen and run software as the logged-in user, and seemingly access their data. If true, the vulnerability means even BitLocker won't help keep customers' files protected.

In a recent development, unsurprisingly, the bug was discovered by Abdelhamid Naceri, the prolific Windows hacker known to the world as Nightmare Eclipse, and is responsible for about a dozen zero-day findings in Microsoft's operating system. The exploit requires physical access to the machine, but that's precisely the scenario that lock screens and/or BitLocker are supposed to protect against.

Industry observers note that to trigger the vulnerability, all you need is a keyboard. In the Windows 11 lock screen, click "Forgot my PIN," then hit Win+U to bring up the voice narrator. The window will be hidden behind the lock screen, which, for practical purposes, is just a veneer, but you can interact with it using the keyboard if you hold down the Caps Lock key and use the arrows and Enter.

Industry observers note that after some brief navigation through Narrator, you'll actually be in Settings, and then have multiple avenues for further shenanigans. One obvious one is going into Bluetooth and Devices and setting Autoplay to show a USB stick's files and folders, then plugging in your own with your software of choice to run. Additionally, on a personal machine, the user is bound to have administrator permissions, so you can just create your own account.

Sources indicate that this bug is quite fresh, so there isn't widespread reporting or testing. The author claims "the vulnerability seems to be extremely consistent in every machine I tested it in." We did encounter a sysadmin on Reddit, danrhodes1987, who claims they've tested it on machines they manage, and sure enough, it works, though only on their InTune-enrolled devices. He states that "you can launch anything you want in the context of the user logged onto the device.".

Sources indicate that additionally, they found it possible to invisibly navigate whichever programs the user had open before they locked their screen, which all but guarantees that the victim's entire data and programs will be fully accessible. As a Windows sysadmin friend of mine remarked, Windows' lock screen implementation always felt like a kludge, and he posits this won't be the last hack found for it.
