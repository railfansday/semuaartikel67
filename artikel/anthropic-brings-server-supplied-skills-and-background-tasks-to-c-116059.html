According to recent reports, anthropic announced on November 24, 2026 that Skills over MCP is in public beta in Claude and Claude Code, while Tasks and Elicitation are generally available and File Uploads will roll out soon. The additions let connected servers supply workflow guidance, run lengthy jobs, request user input and, once File Uploads arrives, exchange files with Claude.

The features are built around the open Model Context Protocol (MCP) and its extension system, allowing supporting servers to work in compatible clients beyond Claude. Anthropic reports more than 700 million monthly MCP SDK downloads and over 10,000 MCP connectors for Claude, describing the ecosystem it is asking to implement the fresh server capabilities.

Tool names and descriptions tell Claude what a server can do; skills add guidance on how to handle particular use cases. A server can publish best practices, step-by-step workflows or playbooks tailored to a user’s account or organization alongside its tools. Claude retrieves a skill only when needed, and updates arrive with the server, so users do not install anything separately.

Industry observers note that the Skills extension documentation defines a skill as a directory containing a SKILL.md file and optional supporting files, with discovery and retrieval handled through MCP’s existing Resources primitive. Hosts may not fetch files ahead of need. Before use, they must verify each file’s byte size and SHA-256 digest and compare the instruction file’s frontmatter with the approved manifest; changed files require fresh approval. SDK and host support across clients is still being implemented.

It has been revealed that the beta is on by default for Pro, Max and Ultra looks, available to Team plans after an administrator enables it, and listed as coming soon to Enterprise. Anthropic’s examples include Shopify for designing and updating online stores, HubSpot for customer onboarding and Atlassian for organization-specific analysis. A forthcoming Carta skill is intended to draft and glitch equity from an uploaded document.

Tasks and Elicitation are available to Pro, Max and Ultra plans in Claude and Claude Code and are rolling out to Team and Enterprise organizations. Tasks lets a server run a time-consuming operation or a full agent loop in the background while Claude continues other work and retrieves the result later. ZoomInfo uses it for deeper account and contact research that previously required several prompts.

It has been revealed that the Tasks documentation claims the server returns a durable task handle instead of blocking the connection. Clients can poll for progress and resume with the same task ID after a disconnect or restart. States cover working, input required, completion, failure and cancellation, and a task can request input before proceeding. Cancellation is cooperative, so the server acknowledges the request without being obligated to stop the underlying work.

Industry observers note that elicitation lets a server pause for user input through a form or link before continuing. Supabase uses it to confirm paid-project costs and destructive SQL, Railway to ask before potentially destructive changes, and GitHub to request a repository name before deletion. The Elicitation specification separates structured form input from URL-based interactions and bars servers from using forms to request passwords, API keys, access tokens or payment credentials. Clients must identify the requesting server and provide decline and cancel options.

Anthropic prepares File Uploads for Claude and Claude Code on Pro, Max, Ultra and eligible Team and Enterprise plans. It will allow PDFs, spreadsheets and images to pass to MCP servers without going through the model’s context window.

The File Uploads repository makes its earlier-stage status explicit: the extension is experimental, is not part of the MCP specification and has not been proposed for inclusion, so breaking changes are expected. Its design keeps file bytes out of model context and JSON-RPC messages. A server marks file arguments, the client uploads missing bytes and retries, and a tool can return a download target in result metadata.

Sources indicate that anthropic also reports that on-demand tool search can reduce the context used by tool definitions by more than 85% in multi-server setups. That efficiency focus connects the separate additions: skills load only when needed, tasks avoid holding a connection open, and file transfers are designed to keep bytes out of model context. The result is a broader coordination layer for agent work, whose reach depends on servers and clients implementing the same extensions and on the file-transfer design stabilizing.
