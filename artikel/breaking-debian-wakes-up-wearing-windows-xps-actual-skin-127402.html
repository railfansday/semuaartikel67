Win4Wine runs the genuine Explorer shell atop Linux.

It has been revealed that win4Wine is one of the more remarkable and creative hacks we've read about in recent years. It runs Windows XP's genuine Explorer shell through patched Wine on Debian 13, with a custom window manager integrating Linux applications into the desktop.

As its GitHub repository explains: "The taskbar, Start menu, desktop and folder windows are XP's real ones, and Linux applications get XP's frames and taskbar buttons.".

This impressive, possibly demented project has English installation instructions and a README, although its design documents are in Japanese. We found Mozilla's built-in translation handled those pretty well.

Its developer goes by miKuta0407 on GitHub, their homepage, and X.

Also note, you're going to need some Windows installation media for the full experience. The README says: "No Microsoft files are included. Only the files that are needed are extracted locally from your own ISO.".

In a recent development, it supports Windows XP Professional SP3 installation images in 32-bit Japanese or English editions, with an experimental option for Windows 7 SP1 x64. Without either Windows image, it can download and use ReactOS's free software shell instead, for what it terms "a Windows 2000-like classic look." In our view, that sounds much better anyway.

Recent findings suggest that before any former Windows users cry hurray and reach for an optical drive, this is not some ready-to-run project. The top of the README warns: "This is a personal, experimental project, not a finished product for daily use." The developer has tested it only on a fresh Debian 13 installation and recommends a VM or spare machine, rather than an existing working desktop, which sounds like an excellent precaution to us.

Also, before you ask, yes, it was vibe-coded with Claude.

According to recent reports, we found ourselves reminded of another crazy-but-is-it project that we wrote about back in January: What if Linux ran Windows... and meant it? Meet Loss32. The Loss32 proposal was even more extreme. It suggested replacing essentially the entire Linux userland, so it would be a Linux kernel running Wine with a Windows desktop and Windows apps.

Industry observers note that however, Mikuta-san was way ahead of us – lower down, the README mentions and even links to Loss32. Saying that, since it debuted at the end of 2025, the bottom of the Loss32 web page demonstrates a couple of updates, reporting on delays in getting it working. That, to be honest, did not shock us, but we still admire the let's-do-this spirit. The developer also seems to have got slightly distracted by a previous project, touchHLE: high-level emulator for early iOS apps.

Loss32, in turn, reminded us of Neptune OS, an attempt to give seL4 a Windows personality transplant. We wrote about that back in 2022, and work on it has continued: the project page shows updates in recent months. The team has also pushed out preview releases in 2022, 2024, 2025, and most recently in September.

Recent findings suggest that this OS face transplant also reminded us of our article, Classic 7 is Windows 10 LTSC cosplaying as Windows 7. Some people really miss the look and feel of vintage Windows. Can someone do Windows NT 4 next, please? ®.
