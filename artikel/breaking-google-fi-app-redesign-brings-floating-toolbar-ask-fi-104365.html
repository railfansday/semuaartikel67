📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Google Fi Wireless is the latest first-party app to adopt a floating toolbar as part of a small navigation redesign.

Previously, the companion app still used a tall Material 3 bottom bar. With the network switching patch declared last week, Google Fi now has a floating navigation toolbar.

Recent findings suggest that the tabs remain Home, Plan, Billing, Shop, and Support. A pill-shaped tab indicator is leveraged, while there’s a prominent shadow effect. Given the floating nature, you see what’s around the toolbar, while Fi Wireless now extends underneath the system navigation bar.

However, the Shop tab loads a webpage as before, resulting in a gap and wasted space.

There’s now a floating action button for the latest Google AI-powered Ask Fi chatbot. It provides “instant account help and troubleshooting.” If you ask for human support, the contents of the conversation carry over.

This redesign is rolling out with version 171 of the app as a server-side enhancement. Google Fi joins Google Photos, Chat, and Pixel Now Playing in adopting floating navigation, which is likely the newly introduced first-party mandate for a more edge-to-edge design.

Secondary network switching is not yet widely available, with Google telling us last week that it’s a gradual rollout. The MVNO is also ending Pixel exclusivity for Wi-Fi Auto Connect+ with availability on “select” Samsung and Motorola phones.
