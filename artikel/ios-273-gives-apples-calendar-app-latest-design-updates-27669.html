Industry observers note that when you open Apple’s Calendar app in iOS 27.3, the interface will look largely familiar to what was there before. But there are some key design changes that make the app better suited for one-handed use.

Most notably, the buttons for search and for adding a fresh event have both been moved from the top of the screen to the bottom.

This is a welcome change for anyone who uses their iPhone one-handed a lot, as both key buttons were previously in the top-right corner. I normally use my iPhone in my left hand, so they were especially hard to reach before.

According to recent reports, additionally, Apple has moved the current month to the top-center of the screen and added the year too. Because the year is now always prominently visible, Apple removed it from the back button in the top-left.

Industry observers note that finally, the ‘Today’ button that takes you back to the current day has been changed to always show the actual date. So right now, it reads ‘Mon 16.’.
