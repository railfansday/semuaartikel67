Industry News: Overlocker uses vibecoded BIOS modification to target Intel's non-K overclocking restrictions

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

In an attempt to resurrect ASRock's discontinued SkyOC overclocking feature, an enthusiast has vibe-coded a motherboard BIOS using AI, potentially bringing non-K CPU overclocking to modern Intel CPUs. According to a post on X, Hardware 360º used Chat-GPT Astra to decompile and compare two versions of an ASRock BIOS, one released with SkyOC and another with the feature disabled. The AI reportedly identified the code responsible for enabling the overclocking workaround and modified it to create a BIOS ready for implementation on a compatible motherboard. Unfortunately, it remains to be seen whether the modified firmware can restore SkyOC on modern Intel platforms, as the workaround is yet to be fully tested.

It has been revealed that for context, Intel offers multiplier-based overclocking only on its unlocked K-series processors like the Core i9-14900K and the newer Core Ultra 270K Plus. Non-K models have locked multipliers, which restrict users from pushing CPU frequencies. However, there’s another way to raise the speed of a processor by pushing the base clock itself. The base clock, or BCLK, typically runs at 100 MHz and works alongside the CPU multiplier to determine its operating frequency. For example, raising the base clock speed of a CPU to 105 MHz increases the clock speed by 5%. The only downside is that BCLK adjustments can also affect the entire motherboard, including memory and PCIe-based components, thereby potentially causing system instability.

Recent findings suggest that ASRock's SkyOC technology, which was introduced for Intel's Skylake processors in 2016, allowed owners to overclock locked non-K CPUs through BCLK adjustments. Certain motherboards also featured independent clock generators, allowing CPU clock adjustments without affecting the rest of the system. Intel was not particularly pleased with the workaround, and ASRock eventually had to remove SkyOC from its motherboards via BIOS updates. Additionally, Intel introduced microcode changes to prevent non-K overclocking.

In a recent development, the current experiment revisits that workaround by identifying the original BIOS code and adapting it for modern motherboards. Hardware 360º claims Intel's restrictions include a mechanism that triggers a shutdown when BCLK exceeds 103 MHz, and that SkyOC originally worked around this by tricking the processor with a false report of the actual BCLK value.

In a recent development, finding the original code for SkyOC does not necessarily mean it can be successfully ported to a modern motherboard BIOS. Newer Intel processors use different firmware, microcode, and clock-management mechanisms, which would make adapting the workaround considerably more complicated. Flashing modified motherboard firmware also comes with its own set of risks, including the possibility of rendering the board completely unusable. Nevertheless, it is interesting to see how AI-assisted reverse engineering can help gain access to BIOS modifications that would otherwise require a considerable amount of effort.
