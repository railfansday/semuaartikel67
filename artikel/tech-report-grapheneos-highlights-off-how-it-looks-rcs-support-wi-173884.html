📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

RCS is coming to GrapheneOS without Google Messages, as a proof-of-concept app demonstrates how the privacy-focused version Android can implement the messaging standard.

As virtually all Android phones and now iPhone support RCS messaging, the standard is key to communication in 2026. But GrapheneOS owners, by default, are still stuck with SMS/MMS as RCS is typically locked behind Google Messages on Android.

Sources indicate that it’s a problem that Graphene’s developers have been trying to work out for a while now, and it seems progress is being made. A proof-of-concept messaging app with RCS was shared on Twitter/X, showing Graphene’s RCS implementation working with both Google Messages and iOS with end-to-end encryption and full features including typing indicators and reactions.

While this app skips the need to use Google Messages directly, the app does still use Google’s services as most carriers rely on Google for RCS. GrapheneOS still needs a sandboxed version of Google Play, for now, for this to work, but the developers say that a standalone version for carriers that support Google-less RCS will be coming.

Industry observers note that we made a proof of concept RCS messaging app. It already has end-to-end encryption with MLS compatible with Google Messages and iOS, typing indicators, delivery/read receipts, reactions and media/file sharing. We'll use what was learned to integrate RCS into our Messaging app. pic.twitter.com/jzCTCCKrIQ.

There’s still no firm timeline for this newly introduced RCS support on GrapheneOS, but Google Messages can still be used in the meantime.
