Tech Report: Nintendo reinstates SmileBasic 4 to the eShop after it was used for Switch 2 jailbreaks

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

According to recent reports, smileBasic 4, one of the key pieces of software being used to jailbreak Switch 2 consoles, is back on the Nintendo eShop. While the console's firmware has long since been updated to stop known jailbreak exploits, SmileBasic 4 itself has now also been patched.

SmileBasic is a line of programming tools which developer SmileBoom has released for various Nintendo platforms, allowing people to code their own simple programs and games. It's also opened multiple backdoors for jailbreak exploits over the years, first on 3DS, and then on Switch 2.

Technically, SmileBasic 4 is a Switch 1 game, but AI-backed hackers found a way to use it in order to jailbreak Switch 2 consoles, allowing the machines to run code not approved by Nintendo. That would allow customers to, in theory, run homebrew applications, but as far as I can tell, the exploit had not yet been extended to allow people to play pirated games.

It has been revealed that nonetheless, Nintendo acted quickly to delist SmileBasic 4 from the eShop and to patch the console's firmware to address the exploit at a system level. That's a necessary step, too, as SmileBasic 4 was not the only application that could be used to exploit it. Notably, Civilization 7, a game that is available on cartridge and thus impervious to delistings and software updates, could also be used for the jailbreak.

According to recent reports, even so, it seems that SmileBasic 4 itself has been updated to ensure that a similar exploit never happens again. As Twitter user MarioMasta64 notes, the software itself has gotten a upcoming enhancement post-reinstatement aimed at closing the hole used for the jailbreak. The application's demo – which could also be used to exploit it – has also been updated, but it has not yet been relisted on the eShop.
