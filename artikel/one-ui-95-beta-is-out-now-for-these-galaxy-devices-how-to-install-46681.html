Samsung’s beta train has officially left the station, so to speak. One UI 9.5 is starting to roll out to these devices, and with it, some major changes to its Galaxy phones.

There are a couple of reasons the One UI 9.5 beta packs a substantial punch on your Galaxy S26. For one, it’s a halfway mark between Android versions where more useful features can be implemented. Samsung started this trend of releasing the next half-step up in One UI versions with its standard flagships. That’s why, when the Galaxy S27 becomes official, it will launch with One UI 9.5 preloaded.

Samsung details some of the key changes we’ll see in the One UI 9.5 beta, like a latest journaling app and better video/camera controls.

It might be because the Galaxy S27 is the first device slated for the stable One UI 9.5 launch, but the Galaxy S26, Galaxy S26 Plus, and Galaxy S26 Ultra are the only devices that can access the beta revision. The list doesn’t include the Galaxy Z Fold 8 or Fold 8 Ultra, even though they’ve become some of the best devices Samsung has to offer.

It has been revealed that samsung also puts limitations on regions, noting the program will only be open in Germany, India, Korea, Poland, the UK, and the US. Users on other devices outside of those regions won’t be able to download the beta.

That isn’t to say they’re locked out forever. Samsung will very likely expand the beta program before the Galaxy S27 launch, meaning more devices will get access and in wider areas.

Once you finish that process, you should be all set with One UI 9.5 beta.

Recent findings suggest that once again, since it’s early access, you shouldn’t expect things to be perfect. If you find the experience is awful, you can always revert back.

Samsung published the full changelog alongside its OTA revision, as outlined below.

Improved camera controls and zoom bar.

Enhanced Pro and Pro video modes.

More customizable Lock screen clock.

In a recent development, sports animations in Now barAnimation effects are now available for more sports. Celebrate your favorite team’s goals and victories with special visual effects. You can download these effects in Now bar settings.

Privacy display for secure app features (Ultra model only).

Fingerprint and face recognition at the same time.

Redesigned biometric registration.

Auto split and more snap options.

Scan meals and log them instantly.

Track your medications worldwide.

Intuitive floating accessibility shortcuts.

Search for Quick panel controls.

Audio brief and Moments no longer available.

One UI 9.5 beta is available now for the Galaxy S26 series.
