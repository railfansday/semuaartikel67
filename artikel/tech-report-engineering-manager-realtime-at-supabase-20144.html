📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

It has been revealed that supabase is the Postgres development platform, built by developers for developers. We provide a complete backend solution including Database, Auth, Storage, Edge Functions, Realtime, and Vector Search. All services are deeply integrated and designed for growth.

Recent findings suggest that we're looking for an Engineering Manager to lead the Realtime team at Supabase. Realtime lets developers send low-latency messages between clients, track and synchronize user state, and listen to database changes. Those three features are Broadcast, Presence and Postgres Changes. Broadcast also sends from the database and over HTTP, and clients can replay recent messages.

Realtime is a globally distributed Elixir cluster built on Phoenix. The team balances low latency, fair limits between projects, and the cost of running the service. Customers expect connections to stay up, so reliability matters as much as new features.

In a recent development, the Engineering Manager is a people, delivery and technical role. We don't expect you to write production code, but you you will lead a team of experienced engineers. We do expect you to join design discussions and help set the bar for engineering quality, testing and operations.

Build a healthy, high-trust team culture in a remote-first, globally distributed environment.

Run 1:1s, performance management, career development, and onboarding for your direct reports.

Handle people admin (leave, time off, etc.) for your team.
