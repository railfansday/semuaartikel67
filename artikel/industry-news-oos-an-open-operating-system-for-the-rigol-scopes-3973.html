Industry News: OOS – an open operating system for the Rigol Scopes

🌐 Source: Eevblog • 📅 13 Nov 2026 • ⏱️ 1 min read (266 words, 📖 Standard)
  • Normal, peak detect, average, high resolution; memory depth up to 125 M points; 1 ns/div up to roll and scan mode
  • Hardware trigger: edge, pulse, slope, video, pattern, duration, timeout, runt, window, delay, setup/hold, Nth edge
  • Protocol trigger on decoded bus events, zone trigger with boxes or polygons
  • 35 automatic measurements with statistics, delay and phase, cursors, DVM and counter
  • A second pane under the plot: spectrum with peak list, results table, decoder events, or trends of two measurements
  • 8 math channels with free formulas (sqrt(CH1^2+CH2^2)), filters, FFT; reference waveforms, mask test, CSV data logger
  • Spectrum analyser with harmonics, THD, SNR, SFDR, waterfall
  • Eye diagram and jitter (TJ/RJ/DJ, DCD, DDJ, PJ), power analysis, Bode plot with the built-in or an external generator
  • Bandwidth test from a fast edge. OOS does not limit the bandwidth to the rated value
  • From a USB stick, scope closed: DHO800_DHO900_OOS_Install.GEL through Storage > Upgrade of the stock system. Do the dry run first. So far only accepted on the DHO924S.
  • On a second SD card, scope opened: back up the original card, clone it, install oos-.img. The original card stays in a drawer. A second card a few MB smaller than the original works too (tools/sdcard-clone.sh fit).
  • Updates of a running OOS: the .oosupd file through http://:8080/update.
  • Reports from other models than the DHO924S: what works, what does not, the start-up screen and oos-fpgad model
  • Real signals for the protocol decoders, most were only tested with simulated ones
  • Bugs and ideas as GitHub issues, or here in this thread
  • Repository: github.com/deckerjulian/oos
  • How the hardware works: hardware overview
