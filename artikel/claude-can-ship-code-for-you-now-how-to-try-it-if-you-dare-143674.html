Developers are already using Claude Code and other AI-powered coding tools like OpenAI’s Codex in droves, but some still want to check code themselves before pushing it. A latest feature from Anthropic is banking on more adventurous, agent-first coders being comfortable with handing even that last step off to AI.

With Claude Ship, confirmed in beta Monday, “Claude can now review pull requests, fix them, and approve the ones that a team’s policy allows,” Anthropic remarked. The feature is geared toward individual developers or companies who want to move faster or already delegate a significant amount of coding tasks to agents.

“Teams stay in control of where it runs and which changes need a person,” Anthropic noted. “The goal: ship code as fast as teams write it.”.

The latest feature uses two new agents alongside Code Review, which Anthropic released in March for Teams and Enterprise plans. Code Review first collects, organizes, and posts findings to a PR. Then, Anthropic said, the agents, PR Steward and Claude Approvals, guide a PR “through review, fixes, and an approval decision so teams don’t have to manage each step manually.”.

PR Steward can’t approve or merge pull requests, designed instead to participate “on failing CI checks, merge conflicts, and review feedback from Code Review, other review tools, or team members.” It also documents what it changed in each push through comments and provides instructions for how to undo it, should developers want to. Throughout the process, developers can give Claude instructions or tell it to stop by commenting @claude.

According to recent reports, as a final step, Claude Approvals references whatever policy the user or team abides by (which developers provide as a repo file), and additional signals developers set, like Code Review findings, before approving changes autonomously if allowed. If not, it will seek out “deeper human sign-off,” Anthropic noted.

According to recent reports, “It works like a smarter CODEOWNERS file,” the release added. Anthropic stated it recommends that most customers enable those additional checks “first in observe-only mode to build confidence before configuring branch protection to require Claude Approvals’ green light.”.

Admins can select which repos the feature runs in and adjust settings as needed.

But Claude Ship isn’t meant for everyone.

Industry observers note that “Most teams want a person to approve every change, and that’s easy to keep up with when people write every line. But a lot of developers build with agents now,” Anthropic said in the release, noting that its own Claude Code team uses Claude to write a majority of the code it needs.

ZDNET senior contributing editor David Gewirtz said the idea of shipping code at the speed of writing it “raises the hair on the back of my neck.” But he added that, given how impressive Claude Code has been thus far, he wouldn’t be surprised if Anthropic’s deployment tools were equally effective.

“But, it does depend on the team’s workflow and the kind of development they’re doing,” he mentioned. “It’s not something for every team and certainly not for every indy developer, but for certain deployment processes, it could shave a ton of time off turnaround, saving money and potentially sending fixes to customers much faster. ‘Tis cool.”.

Ultimately, Gewirtz mentioned he has reasons to both trust the tool and be concerned about what it means for younger developers in the workplace.

“Since that workflow is often assigned to less experienced members of the team, it’s likely that Claude would be as accurate, although it’s one more way to shut the junior members out of where they add value to the company and grow their skills to become senior decision makers,” he said.

It has been revealed that developer platforms overall are adapting to the latest state of the industry. Entire, a GitHub competitor started by the Microsoft-owned platform’s former CEO, is built around the expectation that developers are working side-by-side with agents.

Individuals with a Pro, Max, or Ultra subscription can use the /ship command now available in Claude Code, meaning “people won’t notice any significant increase in token usage,” an Anthropic representative explained. Team and Enterprise users can use Claude Ship for Github repos, and it is billed on tokens, so your overall bill may change.

It has been revealed that still, that depends on the number of PRs people are putting through Claude Ship — to avoid any surprises, admins can set spending limits for both Code Review and the new PR Steward agent. They can also turn Claude Ship on for an entire repo, meaning developers won’t need the /ship command.

According to recent reports, anthropic added that certain Enterprise organizations “can claim at least $10,000 in Claude Ship credits to use within 30 days of claiming” by Jan. 15, 2027.
