Sources indicate that anthropic is launching a fresh tool for builders called Claude Ship. The new AI feature allows Claude to “review pull requests, fix them, and approve the ones that a team’s policy allows.”.

Claude Ship is a upcoming product created especially for builders who code with agents. The idea is to make handling pull requests as automated as agentic coding.

“That’s why we built Claude Ship, available today in beta,” Anthropic indicates. “It can review PRs, fix them, and decide what’s ready to merge based on policies each team sets. Teams stay in control of where it runs and which changes need a person. The goal: ship code as fast as teams write it.”.

Claude Ship is comprised of three agents: Code Review, PR Steward, and Claude Approvals.

“Together, they take a pull request through review, fixes, and an approval decision so teams don’t have to manage each step manually,” Anthropic states.

“Developers can try Claude Ship on their own pull requests with the upcoming /ship command in Claude Code,” Anthropic says.
