📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Expiring IPv6 routes can bring affected systems down, though corrective patch doesn't require a restart.

Microsoft has released an out-of-band hotpatch to fix a bug in November's Windows Server 2025 security enhancement that could crash some servers when an IPv6 route expires.

The patch for the patch, KB5138318, addresses crashes on systems with Router Advertisement (RA) enabled that receive time-bound IPv6 routes. When a route timer expires, affected servers can halt with error 0x139 (KERNEL_SECURITY_CHECK_FAILURE).

Issued on November 25, the corrective update takes effect without requiring a restart, according to Microsoft.

Recent findings suggest that KERNEL_SECURITY_CHECK_FAILURE means the kernel has detected corruption of a critical data structure and stopped the system. Microsoft has identified route-timer expiry as the trigger but hasn't explained the underlying coding fault.

Good to see the operating system being protected against the impact of the corruption. Less good for administrators wondering why their servers have suddenly misbehaved.

It has been revealed that lansweeper puts Windows Server 2025 at 7 percent of the servers it monitors, compared with 32 percent for Server 2022 and 33 percent for Server 2019. Only systems with the affected hotpatch and networking configuration are implicated.

Microsoft's Windows Server updates have not gone well over the last few months, with out-of-band updates issued in September, October, and November. An out-of-band update to deal with a problem introduced in a hotpatch (in this case, KB5131077) therefore carries with it a certain sense of inevitability.

According to recent reports, hotpatches are a way of getting OS security updates on a Windows Server without requiring a restart and so are, in theory, a boon for administrators keen on maximizing uptime. According to Microsoft, in addition to faster installations and better protection, there is "lower workload impact with less need to restart your machine.".

Recent findings suggest that avoiding a planned restart is less of a selling point when the alternative is an unplanned crash. ®.
