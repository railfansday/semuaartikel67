Disclosure: We built and maintain all five Actors listed below under the publicrecords account on Apify.

A typical research or lead-qualification agent still has to leave the chat to answer five basic questions: what is this website built with, is this phone number even valid, what does Wikipedia say, what is the paper behind this DOI, and what do the domain's DNS, MX, SPF, and DMARC records look like?

We just published five single-purpose Actors on the Apify Store for those jobs. You can run them from the Store, call them over the Apify API, or pin them on Apify's hosted MCP server (https://mcp.apify.com) so Claude, Cursor, or any MCP client can use them directly.

Each Actor has a ready-to-run public task on its Store page if you want to try the prefilled example first.

According to recent reports, tech Stack Detector takes a list of website URLs or bare domains and returns what each site is built with: CMS, ecommerce platform, frameworks, analytics, ad pixels, marketing tools, payments, CDN and hosting, web server, and email provider. Every match includes a category, a confidence level, and the evidence that triggered it.

Public task on the Actor page: allbirds-techcrunch-vercel-stack.

Sources indicate that you get one row per site, with fields such as domain, httpStatus, title, technologyNames, ecommerce, analytics, payments, cdnAndHosting, emailProvider, and a technologies list (name, category, confidence, version, evidence). A run on allbirds.com, for example, returns Shopify, Cloudflare, Google Tag Manager, Apple Pay, and Microsoft 365, each with the header, HTML, or DNS evidence behind it.

Phone Number Validator validates and formats phone numbers against the numbering proposal. It returns whether each number is valid or possible, plus E.164 and national forms, country, calling code, and line type.

This is a format and numbering-plan check, not a live carrier, TCPA, or WhatsApp registration lookup.

Public task on the Actor page: validate-us-uk-au-phone-numbers.

Use phone_extract when the numbers are still inside a block of text rather than a clean list.

Wikipedia Search searches Wikipedia and returns article titles, URLs, last-edited timestamps, and intro extracts, with the CC BY-SA licence line on each row. Turn on full-article mode when you need the page text instead of the intro. The same Actor can also fetch ECB euro reference exchange rates or a U.S. Treasury par yield curve from those official public sources.

Public task on the Actor page: european-central-bank-wiki.

Academic Paper Search & DOI Lookup searches Crossref's index of over 180 million scholarly works, or looks up a list of DOIs, and returns one citation-ready row per paper: title, authors with ORCID, journal, publisher, date, volume and pages, citation counts, funders, licence links, and a retraction flag.

Public task on the Actor page: llm-search-and-nature-doi.

Sources indicate that you can also filter by year range and work type, and sort by relevance, newest, or most cited. DOIs can be pasted as 10.1038/nature14539, doi:10.1038/..., or https://doi.org/10.1038/....

DNS Lookup takes a list of domains, URLs, or email addresses and returns one row per domain with A, AAAA, CNAME, MX, NS, TXT, SOA, and CAA records, plus SPF and DMARC checks, the email provider inferred from MX, and DNSSEC status.

Public task on the Actor page: apify-github-wikipedia-dns.

Useful output fields include exists, dnsStatus, MX records sorted by priority, acceptsEmail, emailProvider, the SPF record and common problem flags, and the DMARC policy (none, quarantine, or reject).
