This Guy Found a Security Camera’s Exact Location Using Only the Sound of Two Planes

Sources indicate that geoguessr is a widely popular online geography game where players glimpse one still frame from Google Street View and then attempt to pinpoint the exact location on a world map. Many things can be helpful hints—the design of road signs, the format of license plates, specific road markings as well as surrounding trees and landscapes. However, a YouTuber named colsto took this idea to a whole new level by geolocating an incredibly grainy video by just its captured audio.

Recent findings suggest that mind you, this audio doesn’t have any useful hints. No one nearby is talking about this “da Bears” game with a thick Chicago accent, for example. But buried within the security camera’s spectrogram (visual display of frequencies over time) is a clue—two of them, in fact. To the uninitiated they look relatively innocuous two sloping lights roughly 920 seconds apart, but colsto recognized these lines as the Doppler effect signatures of a two planes passing overhead.

To start his journey toward pinpointing the location of this video, with the only limitation being it was filmed somewhere in the continental U.S., the YouTuber first turned to Automatic Dependent Surveillance–Broadcast data, or ADS-B, provided by aircraft equipment that constantly report speed, velocity, and altitude. Websites like Flightradar24 rely on this data to provide a real-time snapshot of on-going flights around the world. Colsto first cross-referenced this data and winnowed potential candidates by choosing parameters featuring two planes the right speed and the right distance away while still traveling within 920 seconds of each other. The results weren’t promising.

“That gave us…roughly 70,000 points,” colsto claims in the video. “Now, adding on to all that logic, the silence filter—where that point doesn’t hear another flight between the two events—drops from 70,000 to 15,000. Even with all those constraints, there is just so much land area and so many flights that 15,000 points still meet all those criteria.”.

According to recent reports, instead of going through each data point, ruling out why it doesn’t fit and refining the search parameters, colsto returned to the Doppler curves and revised one of the search’s original assumptions. These two curves didn’t represent a perfect Doppler curve because planes are constantly adjusting speed and heading, and that information—no matter how slight—is locked away within these two curves. So colsto modeled the Doppler curves to create a flight path that could then be checked against 15,000 possible points.

According to recent reports, “The Doppler curve is a function of the radial velocity of the plane with respect to the observer,” colsto indicates in the video. “The Doppler curve would change depending on the plane geometry.”.

Eventually, colsto found the exact security camera located in Oyster Bay in Long Island, New York, that captured the grainy security footage of the pixelated tree line.

Industry observers note that “I’m trying to fear monger with this video. The odds that someone can and does actually do this is pretty slim,” colsto said at the video’s conclusion. “In reality, there’s probably one hundred easier ways to find you than this.”.

That isn’t immensely reassuring.
