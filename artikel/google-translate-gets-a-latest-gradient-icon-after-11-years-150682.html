Google Translate is the latest first-party app to get a new icon, and it comes 11 years after the last redesign.

In a recent development, google last updated the Translate icon in 2015. One thing to note is that the Android app uses a circular version that goes edge-to-edge.

Industry observers note that we’re seeing a new favicon on translate.google.com today. The old paper-esque background is gone, with Google removing the “physical” crease, but the inspiration is still there.

Muuuuuuuch nicer. Brings it up to date with the other newer icon designs.

Recent findings suggest that the corners have been aggressively rounded, while the back layer with the Chinese character for language or writing is now light blue. Up front, the gradient is in full effect. The fresh icon is a bit shorter than before.

This is a much more modern icon that fits nicely with the recent redesigns of Google’s communication and Workspace apps. On Android, it will presumably be placed on a white background.

This icon is not yet live on Android or iOS.
