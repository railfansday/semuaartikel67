Scent and Memory: Why Novelty Boosts Recall in Older Adults

It has been revealed that the sense of smell maintains an unusually direct anatomical highway to the brain’s emotional and memory hubs, bypassing the thalamic relay used by other senses to project straight into the amygdala and hippocampus. Because a single familiar whiff can trigger vivid autobiographical flashbacks, aromatherapy, particularly using lavender essential oil, has frequently been touted as a simple tool to sharpen memory and stave off age-related cognitive decline.

However, rigorous empirical evidence supporting aromatherapy as a universal memory enhancer has remained mixed.

Now, a study published in Frontiers in Aging Neuroscience by neuroscientists at UCLA and Rice University reveals that the relationship between scent and memory depends heavily on timing, sensory novelty, and baseline olfactory health.

Led by UCLA neuroscientist and corresponding author Dr. Stephanie Leal, the investigation demonstrates that while lavender scent alone did not act as a blanket memory booster, encountering the scent as a fresh, novel stimulus at the beginning of a learning session significantly enhanced recall in older adults.

Because age-related olfactory dysfunction is increasingly recognized as an early warning sign of Alzheimer’s disease, Leal and colleagues set out to examine how olfactory cues interact with memory encoding in cognitively healthy younger and older adults.

Participants first completed standardized olfactory assessments to measure baseline smell sensitivity before entering either a room diffused with lavender essential oil or an unscented room. Volunteers viewed two sequential blocks of everyday household objects, such as a tomato or a blow dryer, on a computer screen. Crucially, the design was counterbalanced: participants who experienced the lavender scent during the first image block completed the second block in an unscented room, and vice versa.

According to recent reports, following a delay, participants underwent a nuanced memory test featuring images that were either identical to, slightly altered from (e.g., changing a red blow dryer to blue), or completely different from the original items. This paradigm allowed researchers to separate general recall (recognizing the object category) from high-resolution detail memory (remembering exact visual features).

“When we looked at general and detail memory measures, older adults struggled to remember the details, which we expected,” explained Leal. “Interestingly, the presence or absence of odor made no difference for older or younger adults. We were kind of scratching our heads because that was surprising based on prior work that revealed olfaction might enhance memory.”.

These results suggest that as the brain ages, the specific chemical profile of an essential oil matters far less than the novelty of encountering an enriched sensory environment at the onset of learning.

Rather than treating aromatherapy as a passive background cure-all, the findings indicate that olfactory cues work best when deployed strategically to introduce novelty during upcoming learning experiences.

Sources indicate that “If we want to support memory in older adults, we need to think beyond simply whether a stimulus helps or hurts memory and consider when and how it is experienced,” Leal noted. “A big component of learning in aging is novelty. Engaging in learning in an enriched context may make it easier to learn newly introduced things.”.

By linking baseline smell sensitivity, subjective pleasantness, and timed sensory novelty to hippocampal memory precision, the research offers practical insights for designing enriched cognitive interventions aimed at supporting healthy brain aging.

Does diffusing lavender essential oil automatically improve memory?

No. Researchers at UCLA and Rice University found that overall, both younger and older adults performed no better on memory tests in a lavender-scented room compared to an unscented room.

Why did encountering the scent first help older adults remember better?

Older adults who smelled lavender during the very first learning block recalled objects more accurately than those exposed during the second block. This suggests that the novelty of entering an enriched sensory environment at the start of a task helps the aging brain anchor new memories.

How does sense of smell connect to Alzheimer’s disease and aging?

Recent findings suggest that age-related loss of smell is closely linked to early neurodegenerative changes in Alzheimer’s disease. In this study, older adults with healthier baseline olfactory function, and those who found the scent pleasant, showed better detail memory, highlighting the close tie between olfactory processing and hippocampal memory circuits.

Olfactory context and memory across the adult lifespan: effects on mnemonic discrimination and olfactory function.

Odor is a powerful contextual cue that can influence memory and is closely linked to brain regions involved in episodic memory, including the hippocampus.

It has been revealed that age-related olfactory dysfunction is among the earliest behavioral changes associated with cognitive decline and may contribute to memory impairments in older adults. Hippocampal pattern separation, or the process of reducing interference among similar experiences, provides a sensitive measure of age-related memory decline, yet little is known about how olfactory context influences mnemonic discrimination.

In the present study, we examined whether odor context during encoding affects subsequent mnemonic discrimination in young and older adults. Participants completed a mnemonic similarity task in which object stimuli were encoded in both odor (lavender) and no-odor contexts prior to a memory test.

Across participants, odor context did not significantly influence target recognition or mnemonic discrimination. Consistent with prior work, older adults exhibited poorer mnemonic discrimination and reduced olfactory function relative to young adults.

According to recent reports, however, odor presentation order influenced mnemonic discrimination in older adults, such that performance was better when the odor context was encountered during the first encoding block compared to the second. Additionally, poorer olfactory function was associated with reduced mnemonic discrimination, and this relationship was largely explained by age-related differences in olfactory ability.

These findings suggest that the influence of olfactory context on memory depends on both age and the timing of odor exposure, highlighting the importance of individual differences in olfactory function when evaluating odor-based approaches to support memory in aging.
