Sumo Logic expands AWS Observability Solution with one-click deployment and upcoming regions

UPDATED 09:00 EST / NOVEMBER 16 2026.

Industry observers note that data analytics software firm Sumo Logic Inc. today released an expanded AWS Observability Solution, a monitoring package for Amazon Web Services Inc. people that can now be deployed in one click from AWS Marketplace.

Sumo Logic is pitching the update at cloud teams that would otherwise have to build their own dashboards before they can properly watch an AWS environment. Much of the company’s recent product work has gone into artificial intelligence agents that take on incident investigations.

According to recent reports, support for AWS regions in Zurich, Melbourne and Newly introduced Zealand takes the number covered by the solution to 20. Workloads running in those three regions can now be watched with the same prebuilt alerts Sumo Logic offers elsewhere on 12 core AWS services. Lambda, DynamoDB and Application Load Balancer are among them.

Zurich has been on the firm’s list since February, when Sumo Logic said its security products would come to the AWS Europe (Zurich) Region for customers bound by Switzerland’s Federal Act on Data Protection.

Anyone signing up through Quick Launch, the AWS Marketplace option behind the one-click deployment, can now do the whole thing — buying the package, setting it up and getting it deployed — without stepping outside their own AWS account. Sumo Logic claims the deployments themselves are versioned, in Terraform and CloudFormation alike, which the manufacturer expects will mean less configuration drift over time.

Root Cause Agent, which Sumo Logic put into preview for operations teams on Oct. 13, is where much of the telemetry the package collects ends up. When an alert fires, the agent goes digging through the data on its own. A company blog post from the launch says every finding it turns up can be rerun as a search in one click.

According to recent reports, the agent belongs to Dojo AI, the agentic AI platform Sumo Logic introduced for security operations teams in September 2025. Root Cause Agent carries that investigative work over into observability. Alongside it in October came new Dojo AI packages that bill all of a customer’s agent use, with Mobot, the SOC Analyst Agent and Root Cause Agent included, against one monthly credit pool.

“AI agents are only as good as the telemetry and context provided to them,” mentioned Keith Kuchler, chief product and technology officer at Sumo Logic. Kuchler added that teams on AWS shouldn’t have to keep “working around regions their tools can’t reach.”.

Back in September, Sumo Logic gave customers a way to trim telemetry before ingestion when it expanded its Data Pipelines service. The organization, taken private by Francisco Partners in 2023 for $1.7 billion, will show the AWS package at AWS re:Invent in Las Vegas Nov. 30-Dec. 4.

Through Sumo Logic’s listings in AWS Marketplace, version 3.0.0 of the solution is available now to customers that monitor AWS infrastructure.
