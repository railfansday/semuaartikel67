In a recent development, coding agents can drive a browser over MCP, but most setups start a fresh, logged-out Chromium. Anything behind a sign-in breaks: staging, admin panels, vendor portals.

Oya Browser is a desktop app that gives Claude Code, Codex, Cursor or VS Code their own tabs in a browser that already has your logins.

For CI there's a hosted MCP endpoint and SDKs; health-data teams get an audit trail and a BAA.
