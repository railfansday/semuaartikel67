Sources indicate that samsung is preparing its next major enhancement for Galaxy phones, One UI 9.5, and fresh details have been coming to light. Here’s an overview of a lot of One UI 9.5 updates that have leaked so far.

One UI 9.5 will still be based on Android 17, but it’s set to be packed with various changes based on recent leaks. In particular, it seems like Samsung has a ton of newly introduced AI features in store.

“Galaxy Claw” is supposedly Samsung’s newly introduced “personal agent,” able to leverage apps on your device including your notifications, Contacts, Gmail, Messages, and more. Specifically, Android Authority reports it will be able to use Calendar, Contacts, Gallery, Gmail, Messages, Notifications, Perplexity, Phone, and Voice Recorder, with the agent able to set up scheduled tasks. It does sound like this will be a paid feature, though, with Samsung’s new $4.99/month AI Premium blueprint. There would also be a new dashboard for showing AI usage.

There’s also a newly introduced Memory feature in Bixby that would let the assistant reference past details from conversations or commands.

Daily Brief, sharing its name with Google’s canceled Pixel feature, would be able to summarize notifications from various apps, grouping cards into “Finance and payments,” “Bookings and appointments,” and “Work email,” though that list seems incomplete.

It has been revealed that it’s not all about AI. It also looks like Samsung’s Expert RAW camera experience is being improved with better labels, customizable buttons, a screen lock option, burst mode support, and more. It even seems like there’s video support coming.

It has been revealed that one UI 9.5 will almost certainly be launching on next year’s Galaxy S27 series before expanding to more devices later on, as has been the case for the past several updates. A beta program will likely be available on Galaxy S26 series soon – the One UI 8.5 beta program opened up in early December 2025.
