Sources indicate that google confirmed on November 16, 2026 that Gemini Notebook can turn a notebook’s sources into interactive sites, expanding the research tool’s outputs to include custom visual explainers, dashboards and project trackers. The capability started rolling out globally on the web the same day.

Google is positioning the feature as a faster way to make sense of complex information. It applies to work and study requests, using material already collected in a notebook to produce an interface for a particular task.

According to recent reports, creation begins in Gemini Notebook’s chat. A user enters the command “make me a site” and adds a description of what they want to build for work or study. The request sets the purpose of the site, while the notebook supplies the underlying sources.

Once built, an “Open in a upcoming tab” control lets the user interact with the site outside the chat view. The site can also be shared with others. These options give the result a dedicated viewing space and a way to reach people beyond the original chat session.

Recent findings suggest that google’s examples apply that workflow to three distinct tasks. For exam preparation, a notebook can become a visual explainer such as an interactive periodic table or a historical timeline. Both examples turn study sources into material a learner can explore interactively.

Recent findings suggest that for business data, the announcement describes a dashboard for exploring quarterly sales performance. For project organization, it describes a tracker that lays out tasks and deadlines. The common element across the examples is the combination of source material and a user-described purpose, whether the intended result is study, data exploration or planning.

Sources indicate that A mobile app version is coming soon. The November 16 launch is therefore specifically a web rollout, with mobile availability still forthcoming.

Interactive sites join the source-based formats listed on the official Gemini Notebook product page. Google describes the product as a research and thinking partner grounded in information owners trust and built with the latest Gemini models. The page lists tools that turn files into Slide decks, brainstorms into Mind Maps, assignments into Audio Overviews and textbooks into Video Overviews.

It has been revealed that interactive sites add a user-described interface to that lineup. For Gemini Notebook, the addition makes the user’s intended task part of the output itself: the notebook supplies the source material, the prompt supplies the purpose, and the site provides a shareable interface for working with that material.
