Apple has iPads running macOS already, but don’t get too excited

In a recent development, with iPads running the same chips as Macs, many have wished Apple would give us the option of running macOS on them instead of the somewhat clunky iPadOS windowing system. Apple’s previous arguments against converging devices have been somewhat weakened by the launch of the touchscreen MacBook Pro.

A new report says that Apple already has iPads running macOS internally, and that work on a giant iPad continues, but don’t hold your breath for a public launch of either ….

Sources indicate that as iPad hardware has grown more powerful over the years, the software has struggled to keep up. We saw split-screen capabilities first, with full windowing finally coming to the devices in iPadOS 26 last year.

The UI is still rather clunky compared to macOS, however, leading a significant number of people to wish that Apple simply offered the option of using the more powerful operating system on its tablet devices.

It has been revealed that I would be comfortable with 11" and 13" devices running macOS. Actually, I don’t require them to run macOS itself, but I do need them to run macOS apps. I wish the iPad could match a MacBook’s productivity. Running macOS on an iPad seems like a reasonable idea. The MacBook Air is now the better price choice, while those needing a powerhouse will always choose a MacBook Pro or Studio.

Some suggest that running macOS on iPad would reduce Mac sales, but I disagree. I own a nearly full-spec MacBook Pro 16" and expect to keep a machine like that, yet I also purchased a MacBook Air for lighter travel. I would prefer an iPad over the Air, but I cannot choose it because it lacks the apps I require. If it supported them, I would buy the iPad Pro with all accessories, and Apple would gain more revenue from me. I appreciate the concept of owning an iPad, but presently it lacks the value needed to justify paying more for a device that simply does less than a MacBook Air.

In a podcast Q&A, Bloomberg’s Mark Gurman says that Apple is already doing this internally, but there’s no sign of any plans to make it available outside the firm.

Sources indicate that apple has iPads internally running macOS, and they’ve had that for some time. The fact that they have the underlying architecture of Apple Silicon that’s the same on the iPad and the Mac gives them the flexibility in order to test these types of things.

Recent findings suggest that in terms if they’re actually going to do it – would they bring macOS to the iPad itself – at this point I don’t think that’s going to happen anytime soon. I’ve checked into this and there’s no ongoing operating system project right now in terms of a brand new operating system for the iPad – there is no work being done to consumerize macOs on the iPad.

Gurman notes Apple seems set to continue to make piecemeal changes over time to bring iPad capabilities closer to those of the Mac but is showing no signs of full convergence.

He reiterated that work on a long-rumored giant-sized folding iPad continues.

The other thing I want to say is that I’m really excited for this potential of Project J312. That is, this giant 19-inch, 20-inch foldable iPad. And it’s basically like a gigantic iPhone Duo with no display on the outside.

However, he indicates there’s no guarantee it will ever launch, saying the timings have already slipped from 2027 through 2028 to 2029, but both cost and yield issues may still kill the project. If it does launch, it’s expected to cost anywhere from $3,000 to $5,000.
