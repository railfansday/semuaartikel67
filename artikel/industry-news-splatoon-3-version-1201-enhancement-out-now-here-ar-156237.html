Last week, Nintendo released a major enhancement for its team-based squid-shooter Splatoon 3, bumping the game up to Version 12.0.0.

It has been revealed that it included changes to multiplayer, weapons adjustments, changes to Anarchy Battle, and even a change to the GameChat feature on Switch 2. Now, following this, Nintendo has released Version 12.0.1. The English patch notes aren't live just yet, but it is only a small enhancement compared to the previous one.

Recent findings suggest that according to a rough machine translation, it includes a fix for Anarchy Battle. Here's the rundown via Nintendo's Japanese website. We'll patch this with the English patch notes when they go live.

Fixes for Anarchy Battle (Series).

Fixed an concern in Anarchy Battle (Series) where the matchmaking process would sometimes fail to complete.

According to recent reports, *The latest update data is required to access online features. *Local wireless play is not compatible with versions prior to 12.0.0. Please ensure that all players you are playing with are using the same version of the update data. *Battle Replays are compatible with version 12.0.0, but are not compatible with versions 11.3.0 or earlier.

As usual, certain features such as local wireless and battle replays may not be compatible with earlier versions of the game.

It has been revealed that you can find out more about what Splatoon 3 Version 12.0.0 included in our previous post here on Nintendo Life. In case you missed it, Splatoon Raiders recently got an eShop demo.
