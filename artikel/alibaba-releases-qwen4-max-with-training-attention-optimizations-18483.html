Alibaba releases Qwen4-Max with training, attention optimizations

UPDATED 16:21 EST / NOVEMBER 16 2026.

It has been revealed that alibaba Group Holding Ltd. today introduced Qwen4-Max, its newest and most capable large language model.

According to recent reports, the algorithm not only generates higher-quality output than its predecessor but also costs less. Those improvements are the result of a fresh architecture, Qwen4, that made the LLM’s training run more efficient. Additionally, Alibaba has equipped the model with an upgraded attention mechanism.

Sources indicate that qwen4-Max’s backbone, the part of an LLM that functions as its main processing engine, comprises 2.4 trillion parameters. The model activates only 71 billion at any given time. The backbone is supported by 328 billion so-called N-gram parameters, which function as a kind of cache. They save the results of oft-repeated calculations and thereby remove the need to compute them from scratch every time.

According to recent reports, an LLM’s artificial neurons are organized into sets known as layers. When the model learns something fresh during training, a piece of data called a gradient travels through the layers and refines their output. The gradient moves through them one by one starting from the last layer, which finalizes and displays prompt responses.

In a recent development, qwen4-Max includes a feature that enables the gradient to skip some layers. That feature, or residual, is effectively a shortcut inside the LLM. Its purpose is to reduce errors during the training workflow, which in turn lowers costs and improves output quality.

In a recent development, residuals can also be found in many other LLMs. Historically, the mechanism was implemented as a single gradient transportation channel. Qwen4-Max’s implementation of the technology features four channels. Moreover, those channels have a “gate” that can adjust the movement of gradients to further improve the training process.

Qwen4-Max’s attention mechanism, a module that helps it understand user prompts, features two key customizations. The first is a technology called Gated DeltaNet that lowers the amount of hardware needed to process large prompts. The second optimization, QSA, skips pieces of data that the LLM doesn’t need to answer a prompt. That arrangement further lowers infrastructure costs.

In a recent development, alibaba compared Qwen4-Max with its predecessor, Qwen3.8-Max, using an internal benchmark that includes knowledge work tasks. The former model achieved a higher score and used up to 35% fewer tokens to complete tasks. Those savings grew to 49% when the models were tested using the Terminal-Bench 4.0 suite of coding challenges.

Qwen4-Max is available through Alibaba’s cloud platform. The company prepares to open-source a collection of smaller models based on the same technologies further down the line. It’s also open-sourcing Qwen-Live-Delivery-Plugin, an extension that makes Qwen4-Max better at performing time-consuming tasks.

When an LLM is assigned a long-horizon project, customers often have to wait until the model completes its work before they can review the results. Alibaba’s plugin shortens the wait. It enables Qwen4-Max to promptly deliver an initial draft and then iteratively add improvements. Users can give the model feedback along the way to refine its work.
