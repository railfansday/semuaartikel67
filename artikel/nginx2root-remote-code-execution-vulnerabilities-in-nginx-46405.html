NGINX2Root: Remote Code Execution vulnerabilities in nginx

Xint is reporting that it has discovered a collection of five critical vulnerabilities in the NGINX web server. The worst flaw, it claims, would allow an unauthenticated attacker to execute commands on an affected nginx server with HTTP/2 enabled. The company also reports a local-privilege escalation (LPE) kernel vulnerability, which was introduced in the 4.15 kernel, in the Stream Control Transmission Protocol (SCTP) subsystem. If chained with the NGINX vulnerability, it would allow an attacker to gain root privileges on the host. A kernel patch for this is not yet available.

It has been revealed that xint recommends updating to NGINX 1.31.9, which was just released, and to block the SCTP module on hosts that do not need it until a kernel fix is available. See the mitigations section of their report for more information.
