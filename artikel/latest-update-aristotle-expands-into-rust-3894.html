📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

We’re excited to announce Aristotle’s expansion into Rust, one of the fastest-growing programming languages for high-stakes software.

Recent findings suggest that the expansion builds on Aristotle’s support of C and Verilog and marks a major advancement in our mission to verify all code. Instead of relying on testing to catch every flaw, developers can now use Aristotle to prove their Rust code works as intended before it ships, providing a fresh level of certainty to systems where even a single bug can be catastrophic.

With support for Rust, Aristotle can prove that your code has no undefined behavior and does exactly what its spec claims, even inside unsafe blocks. If you’re rewriting C in Rust, it can prove the new code behaves the same as the original.

“Rust is where much of the world’s most critical new code is being written, and increasingly, AI is the one writing it,” stated our CEO Tudor Achim. “With Aristotle, organizations can now prove their code does exactly what it’s supposed to, from the smart contracts that move money to the infrastructure that keeps systems running.”.

Industry observers note that rust powers software across mission-critical industries, from cloud computing and cybersecurity to automotive, aerospace, and financial services including crypto. It’s the backbone of Solana’s smart contracts that drive trading, lending, payments, and other DeFi services on the Solana blockchain.

Recent findings suggest that these systems have no room for error. Smart-contract transactions can’t be undone, so a single missed bug is all attackers need to drain hundreds of millions of dollars. Instead of relying on slow, manual audits that are outdated immediately after they’re published, Aristotle runs on every fresh line of code, proving it behaves as intended across all possible inputs and catching critical flaws before code goes live.

You can see it on real Solana programs. On Manifest, an open-source order book, Aristotle proved 28 results across the whole order book, including that a valid swap goes through, and found a rounding bug the team has since fixed. At Project 0, a prime broker, it proved the books stay consistent through deposits, withdrawals, borrows, repayments, and liquidations, in any order.

To bring that protection to more developers, we’re partnering with the Solana Foundation to support established Solana programs and help new builders verify their smart contracts.

“When software moves real money, security has to keep pace with every code change,” said Ludo Galabru at the Solana Foundation. “Aristotle makes formal verification more accessible to Solana developers, helping teams check critical properties of their programs before launch and keep verifying them with every revision.”.

According to recent reports, aristotle for Rust is available today. Get started at aristotle.harmonic.fun with self-serve, consumption-based pricing, or contact bd@harmonic.fun for volume pricing, dedicated support, and custom deployment.
