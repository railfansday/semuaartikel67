Apple adds ‘face unlock’ to the iPhone Duo, but it’s not Face ID

One of the top complaints from tech reviewers about Apple’s new foldable, the iPhone Duo, has been its reliance on Touch ID, a technology that’s been largely replaced by Face ID across the firm’s iPhone lineup.

With Monday’s release of iOS 27.3 beta for developers, Apple is addressing that complaint with a newly introduced “face unlock” feature that lets iPhone Duo users unlock their phones using the front camera, rather than waiting for a future hardware upgrade.

To be clear, this feature is not Face ID.

Industry observers note that due to hardware constraints, the iPhone Duo shipped without support for Face ID technology primarily because its thin, foldable design doesn’t offer enough space for the TrueDepth sensor array that Face ID requires. A recent report from Bloomberg suggests that the company is working to change that in a future version of the iPhone Duo. In the meantime, the Duo uses Touch ID for unlocking, authentication, and Apple Pay.

The new face unlock feature, however, will allow owners to swiftly unlock the device using the front camera when the phone is closed. It only works if users have recently authenticated with Touch ID or a passcode. Apple notes that Apple Pay and passwords will still require Touch ID, and users will have to authenticate with Touch ID again after 45 minutes of inactivity.

The move is meant to make it easier for people to use the Duo in the way they’re accustomed to, after years of unlocking an iPhone just by looking at it.

It has been revealed that apple isn’t going so far as to allow face unlock to work across the entire device, though, because the technology isn’t as secure as Face ID. The latter uses Apple’s TrueDepth 3D sensing hardware, which includes a flood illuminator and a dot projector that casts over 30,000 invisible infrared dots onto the user’s face to build a unique 3D map of the face. The system combines this map with attention-awareness checks, making it resistant to attempts to fool it with photos or other 2D images.

According to recent reports, the software revision addresses another complaint by incorporating one of the “hacks” iPhone Duo early adopters were using to force their phone to lock when they shut it. That involved creating a shortcut that would automatically run when the phone was closed. Now, Apple says users can enable this feature directly in Settings, under Display and Brightness.

Alongside the software update, Apple confirmed that more than 200,000 apps are now optimized for the iPhone Duo, up from over 100,000 earlier this month.

Other new features in this latest software release include an option to ask Siri questions about the content of a web page, even portions that aren’t visible without scrolling. Apple is also introducing video podcasts in Apple Podcasts in the Apple TV app, catching up with rivals like YouTube and Spotify.

The iOS 27.3 software update is currently available to developers and will soon arrive for public beta testers. It will roll out more broadly to all users after further testing is complete.
