According to recent reports, ubuntu 27.04, Tenacious T-Rex, is set for an April 22, 2027 release. Although that seems a long way off, it’s sooner than you think. As is implied by the release number, 27.04 is not an LTS release, so it only receives support for nine months (until January 2028). The good news is that you can migrate from 27.04 to 27.10, and then to the LTS release, 28.04. The entire upgrade path ensures that you don’t have to miss a single release.

In a recent development, but what’s coming in Ubuntu 27.04? Given that it’s an interim release, you’re probably assuming that there’ll be nothing exciting to be found. Although there won’t be any game-changing additions, there will be plenty of refinements and bug fixes.

Also: I’ve used Ubuntu for 22 years – and 26.10 might be its best release yet.

Industry observers note that I’ve been using the daily release of Ubuntu 27.04 for a bit. Let’s take a look at what is currently expected in Tenacious T-Rex.

Industry observers note that this is probably the biggest addition to the next release of Ubuntu. And although you won’t find any major changes in GNOME, there are some notable ones. First off, there will be editable quick settings, which allow for customizing, adding, removing, and rearranging toggles and widgets. GNOME 52 will also enjoy a revamped calendar popover, which streamlines the feature to focus primarily on events, time, and weather.

There will also be several improvements to window management, such as a spatial overview and a mosaic/tiling system for auto-resizing and organizing windows, a refined full-screen Alt+Tab app switcher, which will be capable of grouping older windows by application while showing newer ones individually, and finally, the ability to remember window sizing, placement, and workspace.

It has been revealed that desktop search is also getting a bit of polish by way of a redesigned popover and an improved results overlay that includes file previews, multiple actions, and search filters. And, as usual, there will be plenty of bug fixes and performance enhancements. The bump in speed is noticeable, too, in my testing.

Ubuntu 27.04 will ship with the Linux 7.6 kernel, which includes better VRAM management for gaming and expanded support for modern hardware, such as early enablement for AMD Zen 6, stable support for Intel Xe3P, mainline boot capabilities for Apple M3 Pro/Max/Ultra, and initial support for the 2026 Steam Controller.

There will also be performance gains for both the Btrfs and Ext4 file systems, which (along with the improvements in GNOME 52) will make Ubuntu 27.04 one of the best-performing releases in some time.

It may not knock you back to prehistoric times, but Tenacious T-Rex will wow you with its performance and polished looks.
