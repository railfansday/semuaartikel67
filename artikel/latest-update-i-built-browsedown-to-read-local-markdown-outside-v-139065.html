My code is on the left, my AI chat is on the right, and somehow I’m trying to read a Mermaid diagram in a third VS Code pane. By the time I’ve dragged the divider far enough to read the labels, I can barely see my code.

According to recent reports, that’s why I built Browsedown. Right-click your docs/ folder in VS Code and choose Open in Browser. It serves the Markdown locally and opens your README in a browser tab, with the subfolders in a sidebar. There’s nothing to configure or push first.

If the README links to a deployment guide, you can follow the link, read the diagram at full width, and hit Back. On a team call, that’s the tab I’d share when someone asks, “What happens after we merge?”.
