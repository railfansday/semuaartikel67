Fresh Nvidia bug is killing SSDs — is it “AI code incompetence,” owners ask?

In a recent development, if you haven't updated your Nvidia drivers recently, you may want to hold off. A newly discovered bug apparently can damage your PC by writing excessive amounts of data to solid-state drives (SSDs).

It has been revealed that the bug was found in the two most recent Nvidia GPU driver updates — specifically 621.14 and 621.24 — for the Nvidia GeForce Game Ready Driver. The 621.24 update was released on November 12.

Sources indicate that the bug was discovered by TroubleGrid who reported that the bug causes the NVDisplay.Container.exe to write (save data) far too much information to an Nvidia log file that can degrade the SSD. It can result in as much as 30GB per hour.

Sources indicate that the executable already wrote log files before the updates but not that much. SSDs typically take years to degrade, but the excessive data written by this bug can speed up the process causing stuttering and mouse lag.

On Reddit, I've seen a few posts about the bug with people complaining that this is why you never enhancement. "By principle I never ever update my drivers unless there are feature inclusions for let's say a newly introduced game I bought," one Redditor mentioned.

Plenty of others agreed with that sentiment, and I'm inclined to say they're correct here.

The other half of the comments split between blaming AI-written code. Before his ouster, CEO Jensen Huang was pushing for Nvidia engineers to use more AI-generated code via chatbots and agents.

Or they were of the belief that Nvidia is purposely killing drives to force customers to pay more for upcoming ones. Several called out Sam Altman and his recent claim that laptop RAM is a "terrible" allocation of a scarce resource.

"I honestly would not be surprised if they are doing this on purpose to kill our NVMe's," wrote a poster.

If we were to put blame on something, at this point, I'd say its AI-fueled incompetence, not AI-fueled greed, though that has led to noted stupidity.

The easiest fix is to rollback your graphics card driver to version 621.01, which is the last known patch to lack this bug.

Sources indicate that troubleGrid listed a manual fix that requires you to set the Nvidia Display Container LS service to manual. Though it'll cost you. Basically, this can disable the Nvidia Control Panel and Nvidia App, meaning G-Sync color settings, display scaling, resolution overrides and more will not rock. "Do not disable the service outright if you use G-SYNC or a custom colour profile," the report warns.

If you need a temporary fix, you can stop the service, delete the log file and start again. However, the file will return and continue to grow in size.
