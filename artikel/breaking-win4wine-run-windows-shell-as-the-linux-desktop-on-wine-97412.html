📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Linux のデスクトップを、Windows XP のシェルで。.

個人の実験的なプロジェクトです。 日常の作業環境として使えるほど完成してはいません。 動作を確かめているのは、新しくインストールした Debian 13 に導入スクリプトで入れた場合だけです。 すでに使っている環境（ほかのデスクトップ環境やディスプレイマネージャが入っているものなど）への導入は試していません。 試すときは、仮想マシンや試験用のマシンをおすすめします。.

Windows XP の explorer.exe を、パッチを当てた Wine の上で Linux のデスクトップシェルとして動かすプロジェクトです。 タスクバー、スタートメニュー、デスクトップ、フォルダウィンドウは XP 本物のものです。Linux のアプリも、XP の枠とタスクバーで扱えます。.

Microsoft のファイルは同梱していません。お手元の XP の ISO から、必要なファイルだけを取り出して使います。.

XP の ISO が無い方は、XP のシェルの代わりに ReactOS のシェル（Windows 2000 風のクラシックの見た目）でも 試せます。ReactOS は自由なソフトウェアなので、導入スクリプトが公式のリリースから取得します（docs/reactos.md）。.

Windows 7 の ISO があれば、Windows 7 のシェル（Windows 7 ベーシックの見た目）でも試せます。まだ実験的な試作です（docs/windows7.md）。.

XP の ISO が無いときは、ReactOS のシェルで試せます（ISO は要りません）。.

ログイン画面でセッション「ReactOS Shell (Wine, X11)」を選びます。.

Windows 7 のシェル（実験的）は、Windows 7 SP1 x64 の ISO から作ります。.

ログイン画面でセッション「Windows 7 Shell (Wine, X11)」を選びます。.

詳しい手順とオプションは 🔗 導入手順（INSTALL.md） にあります。Wine をソースからビルドするので、4 コアで 1 時間半ほどかかります。 テーマ（XP のクラシックなど）と文字の大きさは、後から変えられます（見た目と文字の大きさを変える）。.

LGPL-2.1-or-later（Wine と同じ）です。対象はこのリポジトリのコードとパッチだけです。 ただし wayland/patches/labwc/ は labwc と同じ GPL-2.0-only、wayland/patches/wlroots/ は wlroots と同じ MIT です。 Windows XP と Windows 7 のファイルと、スクリーンショットに写っている XP と Windows 7 の画面の著作権は Microsoft にあります。 ReactOS のシェルで使う ReactOS のファイルは、ReactOS のライセンス（GPL-2.0-or-later、DLL の多くは LGPL-2.1-or-later）に従います。.
