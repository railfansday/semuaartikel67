In a recent development, radio and TV broadcasts will be interrupted for about one minute at 2:20PM ET on Tuesday while FEMA and the FCC test the country’s Emergency Alert System. Unlike recent communications outages, this is a planned interruption that FEMA is required to run every three years. FEMA notes today’s test includes radio and television broadcasters, cable systems, satellite radio and television providers, and wireline video providers. This test doesn’t include phones.

You’ll hear high-pitched alert tones and the following test message:.

It has been revealed that “This is a nationwide test of the Emergency Alert System, issued by the Federal Emergency Management Agency. This is only a test. No action is required by the public.”.

Radio and TV programming will continue as usual after the test wraps up. FEMA runs tests like this when there’s not an actual emergency so it can find technical and operational concerns with the Emergency Alert System. If there is a real emergency or severe weather event today, the test will run on December 3rd instead.
