Tech Report: Anthropic is trying to kill traditional desktop apps with Claude-generated desktop apps

UPDATED 21:36 EST / NOVEMBER 24 2026.

Rarely a day goes by that Anthropic PBC doesn’t announce some kind of new capability, feature or model, and today wasn’t any different. Today came the ability to use Claude to create fully functional desktop applications for Windows and Mac computers with a single prompt.

It promises to be one of its more impactful updates, fanning the flames of those who argue that artificial intelligence is ultimately destined to eat the software world.

Sources indicate that the organization mentioned today that people can now transform what it calls “artifacts” into standalone applications that run independently of Claude and can be accessed from the desktop. Artifacts have been around for a while, and they can be almost anything, such as a simple order tracker or a meeting dashboard that pulls information from the user’s calendar and email inbox.

Industry observers note that however, until today, artifacts were a bit tricky to access. They could be opened up only from inside Claude itself, which meant users first had to open up the chatbot, login and then find the old conversation where they originally created the artifact they want to use.

Anthropic noted people are using Claude artifacts all the time for various everyday tasks, and so it makes sense to mature the concept. “If you rely on a tool for work, it should open like the rest of your apps and remind you when something needs your attention,” the manufacturer said.

That’s why Anthropic is making it possible for people to use artifacts to create, run and share desktop applications with Claude’s newly introduced “Install as App” feature, which is available in beta now on Windows and macOS.

In a video posted on X, Anthropic indicated how straightforward it is to create a functional desktop app from a simple prompt. The user simply describes the tool they want Claude to create, click confirm and then sit back and wait for a few seconds as it slaps together the required code to bring that app to life.

You can now install Claude artifacts as desktop apps on Mac and Windows.

Because these are “real” apps, they come with their own app icons and they open in a dedicated Window, rather than running within the Claude interface. They also get the ability to send notifications to users, Anthropic stated.

Sources indicate that as an added benefit, Claude artifacts that are transformed into desktop apps will be able to use Claude and various third-party connectors, meaning that AI agents will be able to interact with them autonomously, Anthropic noted. However, the company did warn that any requests made by an app to Claude will count toward their monthly credit usage, which means it could become expensive if an app is used excessively.

In a blog post Anthropic showcased a number of examples of what its internal teams have built, including a fully featured image editing app called Linnet, a file manager with a cinematic design called Phosphor, and a terminal application that integrates with Claude, which is known as Tern.

Sources indicate that there is one major caveat to Claude artifacts-as-apps that sets them apart from traditional desktop applications. According to Anthropic, “you need to be online and signed in to Claude to open an app.”.

It has been revealed that that could be a pretty big downside, for many desktop applications are designed to work even if the computer is not connected to the internet. But those who lack a Wi-Fi connection will be unable to access their Claude-generated apps, even if they’re already built and configured.
