Breaking: Teachback: learning while coding with AI

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Recent findings suggest that after using agents for all sorts of software engineering work, I started noticing that I was retaining less of what I learned. I wasn't the only one: in How AI Impacts Skill Formation, 52 participants with Python experience learned Trio, an asynchronous programming library they had never used before. The paper reports a 15.4% difference in quiz scores, with the AI group scoring lower, and no statistically significant improvement in task time. Among the AI interaction patterns, Iterative AI Debugging had the lowest quiz score, while AI Delegation finished fastest, with an average score of 39%. That led me to create teachback, a tool to help me retain what I'm learning while working with an agent. I also ran a small experiment to see how it worked for me.

I built teachback with inspiration from a second study on metacognitive scripts. The study explores ways to keep people cognitively active while using AI. One idea I took from it is a gate: the agent asks the user to explain not only what a change does, but why it is needed and how it connects to the rest of the project. In the study, participants who used a gated AI assistant repaired a regression in the next phase of the same session at a rate of 61.5%. That was close to the 69.2% rate for participants who worked without AI, and higher than the 23.1% rate for participants using ungated AI. The task was controlled, and the study cannot separate the effect of the explanation from the extra friction of the gate, but the results encouraged me to try the idea.

I built the skill around three parts:.

In a recent development, gate. The agent writes code only after I explain why the change is needed and how it connects to other parts of the project. Simply restating what the code does isn't enough; if my explanation misses the causal link, the agent asks a follow-up question.

Recent findings suggest that solo or worked examples. I write the parts I already know, and the agent reviews them afterwards. For parts I don't know, the agent gives me a worked example that I can extend. The idea is that familiar parts should be straightforward for me to implement, which helps me retain that knowledge. Ideally, this works even better with a memory system, such as ai-memory, so the agent can tell which parts of the project I already know.

Recall. Staying active during a session matters, but I also want to fill knowledge gaps and remember what I learned later. After each gated piece, teachback uses my answers to check for a knowledge gap and asks whether to add that concept to a review list. It uses the FSRS algorithm to schedule spaced reviews, which an agent hook presents at the start of a later session.

Recent findings suggest that the complete protocol uses all three parts. It also leaves debugging to me: the agent won't read my tracebacks or suggest fixes, though I can ask conceptual questions.

I didn't test the recall feature in this experiment. I added it later, and although spaced repetition has support from other research, I haven't tested teachback's recall feature itself.

I compared using teachback to fix prometheus/client_python issue #1177 with full delegation to fix opentelemetry-python issue #5726. The experiment is documented in the learn repository, which kept its original name after I renamed the tool. Before each fix, I answered the same five questions using only the issue description. Eight days after each fix, I answered them again from memory.

I’ve published my answers, the answer keys, and the blind grading results so you can see what I recalled and how the scores were reached.

In a recent development, with teachback, my score went from 1/5 to 3.5/5, a gain of 2.5 points. With delegation, it stayed at 2.5/5, with no measured gain. The ordering matched my prediction that recall would be better after using teachback, although both after-scores were half a point below what I predicted.

Sources indicate that the bugs weren't equally difficult. The delegated bug was more straightforward. The teachback bug was harder: assumptions in the matter description initially sent me in the wrong direction, and I needed context from the agent to understand the problem. So the score difference is consistent with teachback helping me retain more, but this small comparison cannot show that the method alone caused it.

Using teachback took 86 minutes; full delegation took 11 minutes. That's about 7.8 times as long, compared with my prediction of 3 times as long. I think much of the difference came from the bugs: the delegated one was straightforward, while the teachback bug required knowledge I didn't have, and following the matter description alone pointed me toward the wrong solution. The agent had context that helped me, but teachback required me to explain why each step was needed before passing its gates, then implement the parts I could handle myself. That took time. Since I used each method on a different bug, I can't separate the time spent on the method from the time spent on the bug's difficulty. I expect that cost to be worthwhile for complex or sensitive business logic, where not understanding a change creates real risk.

These results are encouraging for teachback: I recalled more after using it in this comparison. But this was one bug per method, and the bugs differed in difficulty. The numbers describe what happened in this experiment, not a general effect we can expect from the tool.

Industry observers note that this experiment doesn't prove that teachback takes 7.8 times—or even 3 times—as long as full delegation. Those times came from two different bugs, and the difference will vary with the task. It also can't tell us how much of the recall difference came from the method: I tried each approach on only one bug, and those bugs weren't equally difficult. Comparing both methods on the same task would bring another problem: after solving it once, I couldn't erase what I'd learned before trying the other method.

Recent findings suggest that so, the experiment suggests that I recalled more after using teachback, but it doesn't establish how much the skill preserves learning or how much time it adds across tasks. I still think it's worth trying. If you want to avoid knowledge gaps while working with an agent, give it a try, open an matter, and let me know what you think.
