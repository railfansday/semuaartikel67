Team Ninja (Nioh, Ninja Gaiden) is the latest game development studio to implement AI into some of its workflow, but producer Kohei Shibata still believes that fun games need to be "crafted by human hands.".

Industry observers note that the producer best known for the tough-as-nails Nioh trilogy and Wo Long: Fallen Dynasty spoke about the controversial tech during South Korea's GCON 2026, in an interview with INVEN Global. "Currently, we utilize AI in QA and various verification tasks to streamline certain workflows," Shibata explained.

Sources indicate that he went on to argue that if AI can "shorten task times," then developers can spend more hours "elevating the game's overall quality" in other ways. "In that sense, using AI is beneficial." Team Ninja isn't fully on board with enforcing the tech elsewhere, though: "Since it's still a newly introduced technology, we are continuously evaluating the most appropriate ways to implement it. I imagine other game companies are facing similar questions." (Good spot, Kotaku.).

Industry observers note that "What matters fundamentally is that a game becomes fun when crafted by human hands. Repetitive, simple tasks that anyone must perform can be streamlined using technology. But ultimately, deciding how to craft the game and what makes it enjoyable must be done by humans. Using AI itself should never become the goal. I believe the principle that humans must think for themselves and finish the game will remain unchanged in the future," Shibata continued.

Sources indicate that generative AI's use in game development is still a hotly debated topic among both players and the people making games, but it's been prevalent nonetheless. A recent report estimated that around 40 percent of game developers were using AI in some fashion, even if lots of them also agreed the tech was harmful. Bigger publishers like Ubisoft and Epic Games are more aggressively pursuing an AI-first future, too.

Recent findings suggest that team Ninja seems to be settling into a middle ground, at least, according to Shibata's statement. Speaking on the studio's approach to difficult games, he noted that a player's failure should never be the game's fault. Dying in a game like Ninja Gaiden or Nioh should always be the result of human error, otherwise death "causes frustration." Finding that perfect, often bloody sweet spot is something only humans can do.
