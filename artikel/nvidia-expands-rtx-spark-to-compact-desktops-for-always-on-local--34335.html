NVIDIA Expands RTX Spark to Compact Desktops for Always-On Local AI

NVIDIA unveiled on November 18, 2026, that RTX Spark compact desktops from ASUS, Dell and MSI are available for purchase, bringing local AI agents, image and video generation, and model fine-tuning to dedicated Windows PCs with up to 128GB of unified memory.

NVIDIA identifies the ASUS ProArt GR1X and MSI EdgeMesa N AI+ Series among the latest desktops. They join the RTX Spark laptops already on sale. NVIDIA lists mini PCs from Acer, GIGABYTE and HP, along with Microsoft’s Surface RTX Spark Dev Box, as coming soon.

Inside, the desktops pair a 20-core NVIDIA Grace CPU with a Blackwell RTX GPU containing 6,144 CUDA cores. Ten-gigabit Ethernet supports transfers of large datasets, model files and creative assets between the desktops and networked storage. NVIDIA rates the platform at up to 1 petaflop of AI performance using FP4 precision.

Industry observers note that NVIDIA’s desktop specifications list the RTX Spark N1X with Windows 11 support, up to 128GB of LPDDR5X memory and a 140W thermal design power rating. The company says the platform can run language models with up to 120 billion parameters and a 1-million-token context, render 3D scenes of 90GB or more in real time and smoothly edit 4:2:2 video.

It has been revealed that A dedicated desktop adds persistence to those capabilities. NVIDIA positions the systems as always-on PCs that can keep agents and scheduled tasks running while a laptop travels or handles other work. For supported tasks processed locally, code and files stay on the PC and those tasks avoid per-token cloud API charges.

Recent findings suggest that development support includes native CUDA and Linux tools through Windows Subsystem for Linux. Agents can be configured through Hermes Agent or NVIDIA NemoClaw blueprints, while Unsloth provides fine-tuning for supported models. NVIDIA Switchyard, now available in Hermes, automatically routes agent tasks between local and cloud models so routine work can run on-device and advanced reasoning can use cloud models.

According to recent reports, those agents can also connect creative applications. A Hermes Agent workflow can link Photoshop and ComfyUI, allowing natural-language instructions to turn sketches into rendered images or animations. An image can be animated entirely on-device, from isolating its subject and defining motion to generating the finished video.

Sources indicate that comfyUI already includes RTX Video Frame Generation and RTX Video HDR. NVIDIA notes a generated clip can be expanded to 60 frames per second and converted to high dynamic range for color grading within one RTX Spark workflow.

Recent findings suggest that blender 5.3 integrates DLSS 4.5 Ray Reconstruction into the Cycles viewport for interactive ray-traced previews of lighting, reflections and materials. The feature requires Blender 5.3 and the latest NVIDIA Game Ready or Studio driver.

Sources indicate that adobe’s contribution includes broader native Windows on Arm support. Substance 3D Painter 12.2 is optimized for RTX Spark with native Arm support in public beta, and Illustrator and InDesign now have native Windows on Arm versions optimized for RTX Spark. NVIDIA reports up to 30% higher performance in Illustrator than in its emulated version.

In a recent development, the desktop’s significance is the combination of persistence and escalation: local models can handle routine work without per-token API charges, yet cloud reasoning remains available inside the same agent workflow. RTX Spark’s compact desktops are built around that handoff as much as around their hardware.
