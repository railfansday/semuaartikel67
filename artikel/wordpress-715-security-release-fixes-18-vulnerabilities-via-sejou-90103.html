WordPress confirmed the release of version 7.1.5, a security upgrade that fixes 18 vulnerabilities plus two security improvements. The update addresses several types of vulnerabilities, including cross-site scripting and SQL injection, as well as an unauthenticated flaw that could lead to remote code execution.

According to recent reports, wordPress 7.1.5 fixes 20 issues covering a range of vulnerabilities across WordPress core. One of the vulnerabilities in particular stands out because it could lead to remote code execution (RCE), a type of flaw that can result in a site takeover.

The first one that stands out is an unauthenticated privilege escalation vulnerability affecting the Template Part block attributes which could lead to remote code execution (RCE), a type of flaw that can result in a site takeover. There is no authentication required to exploit this vulnerability, and it could lead to RCE. That combination is the worst-case scenario for a CMS.

Recent findings suggest that A remote code execution (RCE) is a vulnerability that enables an attacker to run their own code on someone else’s server from somewhere else, usually over the internet. For a WordPress site, that means the attacker can make the web server execute commands of their choosing. From there they can read or change files and make entries to the database, create admin accounts, install backdoors, or inject malware.

Multisite Administrator to Super Admin takeover (Customizer menu previews). This vulnerability requires an Administrator account, but on a multisite installation that means that an attacker who achieves admin level credential on one site can attain control of the entire network of sites.

Unauthenticated stored XSS via shortcode attributes in comments. No login is needed to exploit it. Stored XSS is a type of flaw that can run malicious code in the browser of anyone who views the affected comment, including administrators, which can lead to account takeover.

According to recent reports, wordPress urges site owners to enhancement to version 7.1.5 immediately to address security vulnerabilities. The update is available through the WordPress dashboard or as a download, with automatic updates supported. Security fixes are also available for older affected WordPress versions, although only the latest version is actively supported.
