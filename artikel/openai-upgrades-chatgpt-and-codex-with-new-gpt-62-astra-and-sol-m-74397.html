OpenAI upgrades ChatGPT and Codex with new GPT-6.2 Astra and Sol models

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

OpenAI kicked off the GPT-6 generation with Astra in September, then upgraded Sol to GPT-6.1 a few weeks later at DevDay.

Today, GPT-6.2 Astra and GPT-6.2 Sol are coming to ChatGPT Work and Codex together. OpenAI says both can finish demanding tasks with fewer output tokens, so you can get more done before hitting your usage limit.

Astra is still the model OpenAI recommends for your hardest projects.

Say you have a screenshot of a slide and want the rest of your presentation to look like it. OpenAI states GPT-6.2 Astra can use that screenshot as a template and match the layout, colors, and even the font size.

On the Codex side, OpenAI notes Astra is better at making and testing changes in an existing project.

“Early testers reported cleaner code style and more focused tests, with fewer rounds of revision,” OpenAI indicates.

Sol is the more affordable model for everyday coding and writing, and it gets surprisingly close to Astra on one coding test.

Cognition’s FrontierCode 2.0 measures whether changes to real codebases are good enough for maintainers to merge.

With both models at maximum reasoning effort, OpenAI notes Sol came within half a point of Astra at about one-fifth the cost.

Both models are available starting today in ChatGPT Work and Codex on Plus, Pro, Enterprise, and Edu.

Industry observers note that the $200/month Pro blueprint also gets Ultrafast mode for the first time with Sol. The $500/month Pro plan gets Ultrafast on both models, as do eligible Enterprise and Edu workspaces once an admin enables it.

According to recent reports, how fast is Ultrafast? OpenAI indicates it can generate tokens at up to 4.5 times the standard rate on either model, although it uses more of your allowance. You can switch speeds from the model picker.

Sources indicate that developers can use both models through the API today as well. Astra’s standard input and output prices are 20% lower than with GPT-6 Astra, while Sol keeps its GPT-6.1 pricing.
