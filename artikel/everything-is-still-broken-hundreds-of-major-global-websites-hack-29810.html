In a recent development, LATEST HAVEN, Conn., Nov. 18, 2026 /PRNewswire/ -- Major global websites, ranging from television networks, common business tools, airlines, and financial institutions are but a few of the hundreds compromised across several industries. If a firm's site was not part of the first wave of attacks, it remains a potential victim.

The attack reveals a systemic, persistent flaw present in nearly every customer-facing website: websites execute code in visitors' browsers, where trusted services can become channels for data theft and transaction manipulation.

It has been revealed that "AI tools have accelerated hackers' ability to rapidly discover flaws in website design and exploit them at scale," stated Ross Hogan, CEO of Source Defense. "Controls are available and can be implemented in mere minutes.".

Source Defense researchers independently confirmed seven distinct variants of the malicious code on sites, furthering research published by Scott Helme on November 16 that linked the campaign to a popular website tool, Optimizely. The code was delivered through compromised Optimizely scripts, illustrating how an attack on a shared provider can expose brands and their visitors without a direct breach of the brands' infrastructure.

Optimizely reports they have fixed the vulnerability, removed the injected code, and implemented additional protections.

It has been revealed that A content security policy (CSP) would not protect against such an attack because Optimizely would be approved even though it's compromised. Permission is based on trusting Optimizely's domain; therefore, the browser will accept a compromised script delivered from that same domain.

The Source Defense Platform for Web Control inoculates websites from these types of attacks by automatically applying granular controls on what website components and scripts are permitted to access, alter, and export.

Recent findings suggest that source Defense's investigation distinguished between the presence of injected code and successful payload delivery. On some examined websites, requests to the malicious domain failed. The presence of campaign-linked code therefore did not, on its own, confirm that the payload executed or data was stolen.

"A website can have strong security around its servers and still lack control over the code running in its visitors' browsers," said Hadar Blutrich, Founder and CTO of Source Defense. "Organizations need that control before the next attack reaches their customers.".
