ED: Looking into it, the state of the art for actually-useful RAG is still about 60-100M params, so still way off from what you can fit on a floppy disk. Quantized, you're looking at maybe 25 floppy disks, 30-50MB at 4-bit compressed.

If you're really damned patient and willing to stream from disk, we can go back to 1984-1986 (IBM PC AT / XT + 40MB HDD).
