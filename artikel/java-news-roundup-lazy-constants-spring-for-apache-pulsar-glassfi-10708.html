Nov 16, 2026 5 min read.

This week's Java roundup for November 9th, 2026, features news highlighting: Lazy Constants proposed to target for JDK 28; TornadoVM jitLLM 3.0; point releases of Seed4J; second release candidates of Spring AI and Spring Boot; first release candidates of Hibernate ORM and Hibernate Reactive; fourth milestone release of GlassFish; and the second milestone release of Apache TomEE.

JEP 547, Lazy Constants (Fourth Preview), has been elevated from Candidate to Proposed to Target for JDK 28. This JEP proposes a fourth preview, with no changes, after three rounds of preview delivered in the upcoming release of JDK 27 and JDK 26 through JDK 25. Formerly known as Stable Values and Computed Constants, this feature introduces the concept of computed constants, defined as immutable value holders that are initialized at most once. This offers the performance and safety benefits of final fields, while offering greater flexibility as to the timing of initialization. The name change from Stable Values to Lazy Constants with the release of JDK 26, better captures the intent of a high-level use case. The review is expected to conclude on Wednesday, November 18, 2026.

It has been revealed that build 24 of the JDK 28 early-access builds was made available this past week featuring updates from Build 23 that include fixes for various challenges. More details on this release may be found in the release notes.

For JDK 28, developers are encouraged to report bugs via the Java Bug Database.

The second release candidate of Spring AI 2.1.0 delivers newly introduced features such as: a new DecisionModel API, anchored by the DecisionModel interface, that returns the probability of different outcomes instead of generated text based on yes/no answers, questions about text or a set of fields; and a new similaritySearch(float [], SearchRequest) method, added to the VectorStoreRetriever interface to complement the corresponding overloaded methods, to search with a user's embeddings in more vector stores. Further details on this release may be found in the release notes.

Industry observers note that the second release candidate of Spring Boot 4.2.0 ships with bug fixes, documentation improvements, dependency upgrades and new features such as: support for reading the value defined in a X-Forwarded-Prefix HTTP header in a WebFlux application on Reactor Netty when the server.forward-headers-strategy property is set to native; and a database assigned to the spring.data.redis.database property is now properly applied to master/replica connections if a value is assigned to the spring.data.redis.masterreplica.nodes property. More details on this release may be found in the release notes and this wiki page.

The Spring for Apache Pulsar team has declared that the project is moving as a subproject within Apache Pulsar at the Apache Software Foundation to "foster even deeper integration and collaboration with the broader Pulsar community." As stated in the blog post:.

Bringing this integration directly into the Apache Pulsar project allows the community to streamline development, accelerate feature support, and ensure long-term alignment with the evolution of Apache Pulsar.

Spring for Apache Pulsar 2.0.8, released in October 2026, was the final release under the auspices of the Spring ecosystem.

According to recent reports, the fourth milestone release of GlassFish 9.0.0 provides bug fixes, documentation improvements, dependency upgrades and upcoming features such as: implementation of the Jakarta Persistence 4.0.0-M7 specification with EclipseLink 6.0.0-M1; a move of the Sun Theme module out of the out of the external GlassFish Woodstock Components repository into its own module in GlassFish so that Sun Theme and the Admin Console can be modified together; and an update to versions 1.2.0-M2 and 2.0.0-M1 of Eclipse JNoSQL. Further details on this release may be found in the release notes.

Beehive Lab, makers of TornadoVM, has released version 3.0 of jitLLM, a JVM-native LLM inference and serving engine, delivers notable changes such as: 1.43 times faster startup with GraalVM Native Image; an up to 9.3 times faster prefill phase; and a more efficient reading of model weights by eliminating the copy from the mapped GGUF file into a Apple Metal buffer. More details on this release may be found in the release notes.

It has been revealed that the first release candidate of Hibernate ORM 8.0.0 ships with notable changes such as: an implementation of the Jakarta Persistence 4.0.0-M7 and Jakarta Data 1.1.0-M4 specifications (the latter via Hibernate Data Repositories); and support for coordination of graph-based flushing that builds a dependency graph for pending entity and collection mutations. Further details on this release may be found in the what's new page.

Industry observers note that the first release candidates of Hibernate Reactive 5.1.0 and 5.0.0 provide notable changes such as: the EXTENDED constant, defined in the Jakarta Persistence PessimisticLockScope enum class, now locks the collection tables as intended to align with the same functionality in Hibernate ORM; and an update to the VertxFactory interface to allow for adding observability without changing the functionality in using the DefaultVertxInstance class. These versions are compatible with Hibernate ORM 8.0.0.CR1. More details on these releases may be found in the release notes for version 5.1.0.CR1 and version 5.0.0.CR1.

In a recent development, the second milestone release of Apache TomEE 11.0.0 delivers bug fixes, documentation improvements, dependency upgrades and newly introduced features such as: resolutions to 38 CVEs; completion of their implementation of the Jakarta Authorization 3.0 specification; and TomEE Plume, the enterprise version, now ships the modular EclipseLink JPA artifact instead of the eclipselink Uber-Jar. Further details on this release may be found in the release notes.

The release of JobRunr 9.0.4 ships with bug fixes and one latest feature that improves build caching and security by moving to hardened Docker images. More details on this release may be found in the release notes.

The first rolling release of JReleaser 2.0.0-SNAPSHOT provides a upcoming feature in which the -a and -d short option flags, for their respective corresponding --assembly and --download long versions, were removed from the CLI due to the lack of short option flags for the --changelog and --announce flags. Further details on this release may be found in the release notes.

Sources indicate that versions 2.4.0 and 2.3.0 of Seed4J, formerly known as JHipster Lite, deliver bug fixes, dependency upgrades and new features such as: install Playwrite only on applications that execute the relevant Playwright component tests; and improved efficiency by creating one global Maven cache that is shared by the Seed4J build and every generated Maven application that replaces a Maven cache for each generated application. More details on these releases may be found in the release notes for version 2.4.0 and version 2.3.0.

The Quarkus team has introduced the Quarkus Resiliency Testing utility that allows developers to reproduce various failure scenarios and their respective responses while testing an application with the @QuarkusTest annotation. An example application using this upcoming utility may be found here.
