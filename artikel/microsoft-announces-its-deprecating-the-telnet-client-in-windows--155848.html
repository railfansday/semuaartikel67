📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

In its latest update on deprecated features in Windows, Microsoft casually mentioned that "Telnet Client is deprecated and will be removed from Windows in a future release.".

This may not mean much to you if you didn't do a lot of computer networking in the 1990s or earlier, but the text-based protocol for remotely opening command-line interfaces was a workhorse we used for a bunch of things. It's how antique university lab computers that didn't even have Netscape Navigator installed connected to the internet, how I played text-based online games like the Discworld MUD back in the day, and how we used to connect to our routers.

In a recent development, by default, Telnet didn't encrypt all the data it was swapping back and forth between computers, which is why it's since been replaced by tools like SSH and PowerShell. So it's not a surprise that it's being deprecated, and honestly I'm impressed that it outlived both WordPad and Cortana.

In a recent development, A Windows feature being deprecated means that it won't be in active development and is a candidate for removal in a future patch, so Telnet isn't being 86ed immediately. If you're still using it to test network connections because that's what you're used to then carry on as you were, but get ready to grumble and switch over to PowerShell when Microsoft finally does pull the plug.
