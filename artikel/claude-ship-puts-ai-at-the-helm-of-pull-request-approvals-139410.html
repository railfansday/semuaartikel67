Claude Ship puts AI at the helm of pull request approvals

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Tired of waiting for a meatbag to approve a change? Anthropic has an agent for that.

Anthropic has introduced Claude Ship to review, fix, and approve pull requests (PRs), offering more AI automation to help teams handle the output of AI coding tools.

In a recent development, claude Ship combines the generally available Code Review service with two newly introduced agents in beta: PR Steward and Claude Approvals. It is available to Claude Team and Enterprise customers using GitHub repositories.

Anthropic mentioned: "On the Claude Code team, Claude writes most of our code, and we wanted everything after the PR to move that fast too." Its stated goal is to "ship code as fast as teams write it.".

One consequence of the AI coding revolution is the sheer amount of agent output, which requires review and approval before going live. Claude Ship is one way to address that by automating more of the workflow. PR Steward works through failing continuous integration (CI) checks, merge conflicts, and review feedback. Claude Approvals can actually approve a PR, something that might rattle the nerves of some engineers.

It has been revealed that claude Approvals applies an approval policy, written by the team as a file in the repository. "Claude can approve routine changes on its own if the policy allows it, or can require deeper human sign-off for certain scenarios," Anthropic said.

The organization advised caution: "For most customers, we recommend enabling this first in observe-only mode to build confidence before configuring branch protection to require Claude Approvals' green light.".

While developers can try Claude Ship on their own pull requests (depending on their permissions and the repository's branch rules) with a /ship command in Claude Code, administrators can set up the rules on a repository-by-repository basis. "Claude Approvals starts when a connected repository has a policy file on its default branch, and an admin can turn it off," Anthropic said.

Sources indicate that "Teams set the pace. They can start with one repository, choose a review level and when reviews run, set a monthly spend limit, and run their approval policy in observe mode until they trust it.".

In a recent development, the extra automation also brings extra charges. Usage is token-based, and even observe-only approval policies can incur costs if they invoke classifiers or Code Review.

Anthropic also includes the familiar disclaimer: "Claude Ship uses AI and may miss bugs, security vulnerabilities, or other challenges.".

It has been revealed that the Register spoke to an engineer who works for a company that uses Claude. They were a little cynical about the whole thing, saying: "It just seems like a glorification of what I already use Claude on – git merge or git rebase.

"Our golden rule so far with Git is to limit Claude to read operations there; this layer of separation still lets devs stay in control and allows them a judgment of the AI changes – what to keep, tweak, or commit.

"If that's offloaded to Claude and it has Git history-rewrite access, the devs will lose that overview and judgment opportunity.".

Sources indicate that how much authority Claude receives depends on the organization's configuration. Approval is not the same as merging, and existing branch protections and required checks still apply.

It has been revealed that anthropic's answer to a growing queue of AI-generated changes is more AI. Teams still have to decide which decisions they're prepared to delegate. ®.
