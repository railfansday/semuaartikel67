Snapchat now lets developers build AR Lenses with AI assistants like Claude Code and Cursor

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Industry observers note that snapchat revealed on Wednesday that it’s giving Lens creators the ability to build Lenses using the AI coding assistants they already use, like Claude Code, Cursor, and Codex. Snapchat Lenses, which are a core part of the social network’s platform, are AR effects that let consumers alter their appearance, add digital objects to their surroundings, or interact with animated experiences through the camera.

It has been revealed that the firm is introducing Easy Lens CLI, which builds on its existing Easy Lens tool, which lets creators generate Lenses from a single prompt on the web and mobile. Easy Lens CLI brings that same idea into developers’ existing workflows, allowing AI assistants to handle the technical work while creators focus on the vision for the Lens itself.

Sources indicate that the launch indicates that Snapchat is looking to lower the barrier to creating AR content, while making its platform more accessible to developers who are increasingly using AI coding assistants. Instead of requiring creators to learn how to use Snapchat’s own development tools, the manufacturer is bringing Lens creation into the AI coding workflows they already use, which could in turn expand the pool of people who build for Snapchat.

Developers enrolled in Snapchat’s Lens+ Payouts program can earn from the Lenses they create with Easy Lens CLI. Snapchat notes it paid out $1.8 million to Lens+ community creators last month.

Sources indicate that lens creators can describe the Lens they want in plain language, and their AI assistant handles the process from start to finish, Snapchat says. That includes building with more than 100 AR building blocks and 50 AI asset generators, generating previews, and publishing them to Snapchat and tracking their performance.

With Easy Lens CLI, Snapchat says developers can create everything from Web Lens games with leaderboards to camera effects and beauty filters.

AI assistants can generate assets, build and test Lenses, address errors, and send updated versions directly to the creator’s phone. The fresh capability can take a game from an initial idea to a published Lens in a single day, without developers having to write code themselves, Snapchat says.

It has been revealed that the tool is aimed at different types of creators. The company notes that game developers can bring existing browser games to Snapchat as Web Lenses, while AI creators can use assets from their preferred tools to build Lenses in their own style. Additionally, agencies and brands can turn existing campaign videos, images, and other brand assets into AR experiences with less production time.

Easy Lens CLI runs on Mac, Windows, and Linux.
