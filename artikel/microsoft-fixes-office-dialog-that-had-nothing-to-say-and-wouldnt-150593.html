Update resolves work-blocking popup, but affected consumers may need an administrator command prompt to install it.

It has been revealed that microsoft has released a fix for a baffling bug that threw a blank window over Office applications and brought work to a standstill. The problem appeared when users debuted an affected Office app, which could display an empty dialog box with no text and no buttons.

Because the dialog offered no way to close it, some consumers were locked out of their work entirely, unable to continue until the issue was resolved.

The good news is that there's an update to fix the problem – version 2611, build 16.0.20625.20142. The bad news is that you might not be able to launch the applications to perform the update because of that blank dialog window.

Industry observers note that microsoft instructs affected users to save their work, close all Office applications, and open Command Prompt as administrator. They can then force the revision with: "%programfiles%\Common Files\Microsoft Shared\ClickToRun\officec2rclient.exe" /update user updatetoversion=16.0.20625.20142.

The glitch affects a swathe of Microsoft 365 products – Excel, Word, Outlook, PowerPoint, Access, and OneNote.

People reported the problem on Microsoft's forums, where volunteer moderator Stefan Blom noted that "this seems to be a common error at the moment" and suggested users try an Office repair or the more thorough Online Repair.

According to recent reports, online Repair reinstalls Office, however, some people reported activation and sign-in problems alongside the blank windows, which may hint at the cause. Microsoft has yet to elucidate.

Other people found that rolling back Office resolved the glitch, while several reported that signing in with another application, such as Edge, fixed things.

Sources indicate that for administrators preparing fleets of devices, a dialog that blocks first use creates another deployment headache. One user with E3 licensing reported: "We can't just hand off a staged machine without getting call[s] that our newly introduced people can't get Office to work because of the blank licensing window.".

Microsoft has shared a fix for the problem, but has not stated which versions of its productivity applications were affected, nor has it explained what went wrong.

Industry observers note that the fix is welcome. An explanation of how Office ended up blocking users with a window containing nothing at all would be welcome too. ®.
