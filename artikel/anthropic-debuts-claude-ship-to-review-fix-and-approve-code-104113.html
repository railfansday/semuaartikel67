It has been revealed that I've actually used Claude Code to perform code reviews, and find that it does a pretty decent job. It doesn't flag all kind of nonsense, it does flag clear concerns, it compares the pull request to the requirements in the ticket and determines whether each of the acceptance criteria are met.

Am I ready to trust it implicitly? No, not at all. "Pretty good" is not a substitute for "excellent." But it is a time saver.
