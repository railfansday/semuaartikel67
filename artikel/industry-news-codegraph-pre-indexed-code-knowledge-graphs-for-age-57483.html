In a recent development, rust kernel: Watches file system events, parses code into AST nodes, and updates the graph incrementally. When you edit a function, only that function's subgraph updates. Full re-indexing happens only on initial setup or major refactors.

MCP server: Exposes the graph as a tool boundary. Agents call structured queries like find_callers(function_name) or get_dependencies(module_path). The server translates these into graph traversals and returns results as JSON.

The kernel uses tree-sitter for parsing, which supports 40+ languages. Each language gets its own parser, but the graph schema is uniform: nodes represent symbols (functions, classes, variables), edges represent relationships (calls, imports, inheritance).
