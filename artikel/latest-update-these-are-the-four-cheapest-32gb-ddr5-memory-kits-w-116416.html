Thankfully, there are some decent Black Friday deals on RAM, with 32GB kits starting at $420. The five kits we've rounded up here are all less than $450.

Of course, these aren't deals compared to prices a year ago, but it seems we're a long way from prices returning to that point. If you're also looking for a motherboard and/or CPU, you can generally save more on memory by picking up a RAM bundle.
