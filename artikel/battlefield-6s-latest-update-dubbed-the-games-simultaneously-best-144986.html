Battlefield 6's latest update dubbed the game's simultaneously best and worst patch as it runs into all kinds of challenges

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

There’s been a lot of anticipation for Battlefield 6’s version 1.1.3.0 patch. The patch kicks off the third and final phase of the game’s first season, adding some fresh holiday-themed content. More the new content itself, the enhancement’s biggest additions are almost entirely gameplay-related.

Unfortunately, for as much as the changes in 1.1.3.0 have been well received, the launch has been marred by a series of technical challenges, some of which are a little unusual.

Industry observers note that immediately after patch 1.1.3.0 went live, players on PC started reporting massive stutters that would occur every few seconds. The matter is especially pronounced in Redsec Battle Royale, but much deadlier in traditional multiplayer.

Industry observers note that battlefield Studios quickly acknowledged it, pointing out a workaround that appears to be working for players on Steam. According to those players, going offline on Steam’s friends menu has fixed stuttering for them.

The issue remains for other players on PC, however, and the developer remarked it’s working on a proper fix.

Recent findings suggest that perhaps the most disrupting problem the patch has caused is one that prevents players from being able to interact with the game’s menu. Tiles become unresponsive, or outright unselectable when you try to hover near them.

Recent findings suggest that ironically, the top set of tiles designed to make it easy for players to rapidly jump into the latest content has been the most affected. Restarting the game sometimes fixes the matter, and some players report that it only happens upon first launch after installing the update.

Sources indicate that but Battlefield Studios later clarified that, unsurprisingly, there’s an actual reason behind the bug. Once again, a fix is being investigated, and the developer will offer an update once some progress has been made.

A little further down the list of importance is an concern that stops players from being able to skip tiers within the upcoming Winter Offensive bonus path in the game’s battle pass. BF Studios took out the feature entirely while it works on a fix, so while you can continue making progress in the bonus path, you won’t be able to skip tiers.

Sources indicate that this is all a shame to see. Outside of all the problems, the meat of the latest enhancement has been almost universally praised. The visibility improvements, and netcode updates have been celebrated. Many players were also happy to see meaningful updates to footstep audio and overall clarity.

Sources indicate that it’s also unusual for a Battlefield 6 patch to run into so many concerns at launch. The sentiment around 1.1.3.0 so far is that it’s the game’s best and worst patch yet. Hopefully those issues will be fixed before the development team breaks for the holidays.
