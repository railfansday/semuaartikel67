Latest release helps owners organize project context, carry it between computers, and choose exactly what their models receive.

FORT LAUDERDALE, Fla., Nov. 27, 2026 /PRNewswire/ -- Intersignal LLC today declared Braid 2.2, an update to its free local AI workspace that introduces named memory containers, reviewed memory bundles, searchable project context, and visible context budgets.

According to recent reports, braid connects local model conversations with project Channels, approved rig connections, an agent review Inbox, and built-in Folio publishing. Version 2.2 gives people a more organized way to preserve the mission, decisions, constraints, and next steps they want available in future conversations.

"Running a model on your own hardware is a powerful starting point. Keeping a project moving across conversations and computers is the next practical challenge," remarked David Seaman, founder of Intersignal. "Braid 2.2 lets people decide what is worth keeping, carry it between rigs, and inspect exactly what context their model was given.".

Give Each Mission a HomeMemory containers group related capsules within a Channel. Each capsule contains five editable fields: title, mission, decisions, constraints, and next steps.

According to recent reports, users can search capsule text, filter by container, and inspect the exact size of their selected memory context. A Channel can include up to four capsules within a 12,000-byte serialized context budget.

Recent findings suggest that saving memory and including it in chat remain separate choices. New and imported capsules start excluded. Customers select the capsules they want, enable the Channel's context permission, and choose whether to include that context in a chat request. Editing or moving a capsule clears its inclusion so the changed revision can be reviewed again.

Sources indicate that carry Reviewed Context Between RigsA complete container can be exported as a readable file and imported into another Channel or rig. The destination presents the container and every capsule's exact fields for review before confirmation.Confirmed imports receive upcoming local identities and start excluded from chat. Existing individual memory capsule files remain supported.

Industry observers note that memory files carry selected project context. They do not automatically synchronize computers, publish conversations, or grant permissions to connected AI clients. Chat receipts show the exact capsule revisions supplied to a model.

More Care for Work in ProgressBraid 2.2 also preserves unsent chat drafts when customers switch Channels within the same open window, asks before discarding changed memory fields, and saves capsule text and container changes together. Additional fixes guard against delayed responses changing the active conversation.

The release retains Braid's now familiar chat interface and text effect, reviewed agent proposals, approved rig handoffs, and Folio's workflow for shaping selected material into a public edition.

AvailabilityBraid 2.2 is available at https://intersignal.org/.Customers configure their model server and weights separately. Braid supports Ollama and local or LAN OpenAI-compatible inference endpoints, including servers provided by tools such as vLLM and LM Studio.

In a recent development, about IntersignalIntersignal LLC builds software for local AI, deliberate context sharing, and publishing under human control. Its Braid workspace brings local model conversations, project memory, rig connections, agent review, and Folio publishing into one application.
