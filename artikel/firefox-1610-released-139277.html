Version 161.0 of the Firefox web browser has been released. Notable changes in this release include the ability to assign a shortcut to copy the current tab's URL, addition of a menu item for Tab Groups, and the built-in VPN can be turned off or on for specific sites. There are also a number of security fixes in this release.
