I've decided not to buy a second machine, not only because of the cost, but because I dread going back to the days of KVM switches and eight more cables on my desk. Possibly two mice and two keyboards because I now have a wireless keyboard and mouse and doubt that it will be smooth trying to use them with two different machines.I have no intention of deliberately installing executable AI agents on my "daily driver." Claude Code is not available on the Apple Appstore and does not install through a normal Mac installer. It installs through a command-line script that could do almost anything. Never in a million years would I install a game that came that way. The idea of using Claude Code on the web and copying and pasting the result seems OK, but I think I need to put my project into a GitHub repository so that Claude can see all of the files in it, and as long as it's in GitHub I don't see a lot of harm in letting Claude put its new code there for me.
