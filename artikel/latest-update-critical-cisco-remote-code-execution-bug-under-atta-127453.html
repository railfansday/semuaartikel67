CISA, F6 sound the alarm after PoC exploit made public.

Attackers are currently exploiting a critical vulnerability tracked as CVE-2026-76466 in Cisco Expressway that allows them to remotely execute commands as root without any authentication, according to warnings from the US government and security researchers.

Sources indicate that CVE-2026-76466, which carries a 9.8 CVSS rating, affects Cisco Expressway-C and Cisco Expressway-E gateways configured in clusters, both virtual and physical appliances running vulnerable software. These provide firewall traversal, VPN-less remote access, and call routing for remote users connecting to voice, video, and messaging collaboration services.

The bug involves hard-coded authentication credentials and insufficient certificate validation in clustered Expressway deployments.

At the time, the networking vendor mentioned it wasn’t aware of any abuse of the vulnerability.

That all changed late last week, however, when Russian security firm F6 said it was investigating “the first observed case” of miscreants exploiting CVE-2026-76466, shortly after a public proof-of-concept exploit became available.

“The attackers initially compromised two Cisco Expressway internet-facing devices,” F6’s Cyber Defense Center stated on Thursday. “Through one of them, they gained access to two additional cluster nodes located on the organization’s internal network. After obtaining root access, the attackers began preparing tooling for further lateral movement across the infrastructure.”.

Sources indicate that specifically, the criminals prepared custom Python code to scan the victim’s network and identify files and folders shared over the Server Message Block (SMB) protocol. The scripts were also designed to interact with SQL Server and WinRM, and search GitLab repositories for credentials and other sensitive information.

The Python scripts used in the attack indicated that the operator used an AI assistant, according to F6.

The security shop also noted that one of the key indicators of compromise is a nodeup “wombat@127.0.0.1” entry in the Erlang system log (erlang.log) on affected Cisco Expressway devices.

A day later, the US Cybersecurity and Infrastructure Security Agency (CISA) added CVE-2026-76466 to its Known Exploited Vulnerabilities catalog, and told federal agencies to patch by Monday.

It has been revealed that cisco updated its advisory on Monday to acknowledge CISA’s addition, while noting that it has no direct evidence of active exploitation. The Register reached out to the networking and security vendor for additional details about the scope of the attacks, but did not receive any response. We will update this story as we learn more. ®.
