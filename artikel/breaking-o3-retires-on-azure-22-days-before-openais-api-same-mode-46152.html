Industry observers note that most people track the model maker's deprecation page. But the cloud that hosts the model keeps its own calendar, with its own dates and its own replacements. Azure does, Amazon Bedrock does, Google Vertex AI does. Sometimes the cloud is later. This time it's three weeks earlier.

A second trap: on Azure, your code calls a deployment name you chose, not the model ID. Grepping for o3 finds nothing if your deployment is called reasoning-prod.
