India’s Digital Infrastructure for Governance Impact and Transformation tool can leak data.

India’s free e-government platform has a critical SQL injection flaw that thousands of organizations must patch to protect up to two billion citizens.

The platform is called the Digital Infrastructure for Governance (Impact and Transformation) – aka DIGIT – and is a modular suite that offers common services such as authentication and payment collection. Third party developers can also create DIGIT modules, and plenty have done so and now offer add-ons that handle tasks as diverse as managing birth and death certificates, revenue collection, and running water treatment plants.

DIGIT is ubiquitous in India, where all state and union territory governments use the platform, as do over 20,000 local government entities.

Sources indicate that india also exports DIGIT under its policy of turning software created for its own needs into “digital public goods” (DPI) that it happily gives away to other nations. Nine nations have implemented DIGIT to some degree, among them Mozambique, Liberia, Senegal, Nigeria, Burundi, Ethiopia, Indonesia, Jamaica, and Sri Lanka.

Sources indicate that india’s population is 1.4 billion. Indonesia’s is 280 million and Nigeria is home to 240 million. DIGIT is therefore used by governments that serve over two billion people, some of whom are now at risk thanks to CVE-2026-136706, a 9.3-rated SQL injection flaw present in DIGIT which allows “improper neutralization of user supplied input while constructing SQL queries and execution in the affected User and Access Control Service components.”.

Recent findings suggest that “An unauthenticated remote attacker could exploit this vulnerability by sending specially crafted input through the affected API endpoint to the targeted system,” according to CERT-IN. “Successful exploitation of this vulnerability could allow the attacker to execute arbitrary SQL queries, potentially resulting in unauthorized disclosure, modification or deletion of database information on the targeted system.”.

eGov India, which oversees work on DIGIT, has released source code for an enhancement that fixes the problem.

While local government users of DIGIT typically access it as SaaS, through large implementations run by national or state governments, over 1,000 deployments are live across various cities and other entities.

It has been revealed that those orgs can therefore add patching DIGIT to their urgent to-do lists, along with fixing Java, PHP, vCenter and any other widely used technologies that suddenly need an urgent security revision. ®.
