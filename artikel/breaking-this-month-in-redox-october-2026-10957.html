Redox OS is a complete Unix-like general-purpose microkernel-based operating system written in Rust. October was a very exciting month for Redox! Here’s all the latest news.

If you would like to support Redox, please consider donating or buying some merch!

Sources indicate that wildan Mubarok ported the official Go programming language compiler after months of porting iterations. It supports both cross-compilation and self-hosted compilation of Go programs.

According to recent reports, the Go compiler uses relibc and does not require an external compiler (GCC). During porting this compiler, it revealed concerns in many parts of the system, such as the range-tree library fix mentioned below.

The Go compiler port is presently a fork, as upstreaming will be another effort.

MJ Pooladkhay was able to boot Redox on Cloud Hypervisor, as part of his NLnet-funded work on Redox virtualization. This is an crucial step towards Redox as a web server in the cloud. He also added integration to the Redox build system, to simplify testing.

He wrote this article about this initial work.

Read this page to learn how to use it.

Wildan Mubarok fixed the missing codecs in GStreamer using FFmpeg libraries for video playback in WebKit.

Industry observers note that wildan Mubarok ported GIMP after some months of work. As GIMP uses the recent Orbital backend of the GTK port, the experience may not be smooth in this initial port.

Wildan Mubarok updated our Servo fork to version 0.7 after months of work to fix regressions and new bugs.

Ribbon tested the Ratatui 3D rendering of Cornell box demo from ratatui-3d project.

The first real hardware NUMA tests on a Dell Poweredge R420 server were done, which confirms that EuclidDivisionLemma’s effort on NUMA support is complete enough to work.

Tests conducted by EuclidDivisionlemma, showed, on average, a 45.2% reduction in time taken on the NPB MG Workload.

lbecher fixed RISC-V dynamic linking, which is the last CPU architecture using static linking in our build system.

It will allow our application testing in RISC-V to easily scale.

Wildan Mubarok finished the first part of rootless package installation code, which allows the creation of system-wide paths mappings to user equivalent paths.

Anhad Singh, Ibuki Omatsu, 4lDO2 and Ron Williams wrote a technical report of the conclusion of the Redox Ring Buffers project.
