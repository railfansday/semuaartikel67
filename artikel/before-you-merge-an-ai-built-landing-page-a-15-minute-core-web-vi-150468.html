Disclosure: I work on VibUI, a paid catalogue of website prompts. It appears once, near the end. The review below needs only a browser and whichever AI tool you already use.

Short answer: an AI-built landing page can look finished in the preview and still fail on speed: an oversized hero image delaying the main content, elements that jump as fonts and images load, and scripts that make taps feel slow. Spend fifteen minutes on three metrics (Largest Contentful Paint, Cumulative Layout Shift and Interaction to Next Paint), write each finding back into the prompt as a constraint, and regenerate only the section that failed. This applies to output from v0, Lovable, Bolt, Cursor, Windsurf, Claude, ChatGPT, Gemini, Replit, GitHub Copilot, Framer AI, Google Stitch, Readdy, Aura.build and OpenAI Codex.

The gain is small and concrete: a page you can hand to a client or ship without a "why is it slow on my phone?" follow-up. It is not a promise of any ranking or conversion change.
