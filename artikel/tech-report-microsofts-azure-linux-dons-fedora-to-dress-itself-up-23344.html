Tech Report: Microsoft’s Azure Linux dons Fedora to dress itself up for mainstream workloads

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Version 4.0 of Redmond’s cloudy OS is free to use in its cloud. Repeat. Free to use.

Microsoft has issued version 4.0 of its very own Azure Linux, which it built atop Fedora for the first time and now suggests is ready to run mainstream workloads.

Redmond’s history with Linux is long and tangled. Former CEO Steve Ballmer infamously labelled the project a cancer but by 2015 Microsoft had quietly adapted the OS to power some switches in its Azure Cloud.

Microsoft then built some of its own Azure services on containers and created a lightweight Linux for them to run in. In 2020, Microsoft released that Linux as CBL-Mariner, largely so that developers who used services like Azure Kubernetes Service (AKS) that relied on the OS could access the platform they were building for.

In a recent development, in 2022, CBL-Mariner became Azure Linux 2.0, another container-centric lightweight release. Version 3.0 followed in 2024, now billed as ready for “broad Azure usage” with Azure Kubernetes Service.

According to recent reports, in June 2026, Microsoft announced version 4.0 and billed it as suitable for Azure Virtual Machines, VM Scale Sets, and container images. The massive change that made that repositioning possible was basing the OS on Fedora rather than Microsoft’s own Common Base Linux.

Microsoft also tuned the Linux kernel – version 6.18 LTS – by adding Hyper-V guest drivers and other features that make it behave well in Azure. It also natively supports tools like Microsoft Defender for Cloud, Azure Monitor, and the Azure CLI, which Microsoft reckons committed Azure consumers already employ and therefore want to apply to their cloudy Linux workloads.

Or as Redmond puts it: “the familiarity of [the] RPM package ecosystem, while adding Azure-native security, compliance, and operational capabilities.”.

All of those changes add up to an OS that Microsoft says is worth a look “Whether you're running web applications, databases, or GPU-accelerated AI/ML workloads.”.

Redmond makes that recommendation in part because Azure Linux comes with “no additional OS licensing cost.” Other commercial Linux distributions will cost users money, meaning Microsoft can now make an argument that SUSE and RHEL subscriptions might be superfluous for both AKS users and those who use Azure to host other applications on Linux.

In a recent development, azure Linux 4.0 debuted last Thursday and is available here. Redmond’s latest Linux debuted just days after Microsoft issued a monster upgrade to version 3.0. ®.
