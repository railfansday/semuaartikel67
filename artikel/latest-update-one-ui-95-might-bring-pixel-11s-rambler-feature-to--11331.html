The Pixel 11 launched with one AI tool most people got on board with, called “Rambler.” It’s a transcription tool that overhauls and cleans up voice-to-text messages. Too bad this Rambler clone will only be available on Samsung Keyboard.

According to recent reports, the Rambler-like keyboard feature was found in an internal test build of Samsung’s One UI 9.5, thanks to SamMobile. The settings include a feature named “Refine Voice Input,” and the description removes any doubt that it might be something other than a Rambler clone.

In a recent development, clean up filler words, hesitations, and more. Text appears after you finish speaking.

Much like the Pixel 11’s Rambler tool, the final product is only available after you’re done dictating. The audio is then processed and turned into something coherent, devoid of the onomatopoeic words we often say when gathering our thoughts in a voice-to-text message. Unlike Rambler, though, it sounds like Samsung’s tool will automatically process your message instead of requiring an end action, like tapping the checkmark.

It has been revealed that the biggest downside to this Rambler variant is that it falls under Samsung Keyboard’s feature set, not Google Keyboard. Even though One UI 9.5 is largely based on Android 17, Samsung still offers its own keyboard as the default experience.

Sources indicate that this isn’t the first Google Keyboard feature Samsung Keyboard has emulated. Magic Cue was a massive addition to Samsung Galaxy devices, in the form of Now Nudge. It works wonderfully if you happen to like using Samsung Keyboard.

In a recent development, google still hasn’t made Rambler available for any other Pixel devices besides the Pixel 11, and it’s the same story for Google Keyboard builds on Galaxy devices. Workarounds exist, but they aren’t official and shouldn’t be treated as such.
