📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Following the last upgrade in August, Google is rolling out a sizable update to Pixel Journal that adds Recorder audio entries and file exports.

Revision 11/16: Updates for Pixel Journal (version 2026.10.27.x) and Pixel Recorder (4.2.20261001.x) are widely rolling out. After installing (be sure to open the apps and Force stop), you’ll see “Record new audio” and “Add existing recording” in the Add item menu.

Sources indicate that the first option directly launches the Recorder app into a upcoming session, while the second brings up a list of previous recordings. The Journal app will show an inline audio player and transcript, which can be removed.

Curiously, these updates weren’t mentioned as part of the November 2026 Pixel Drop.

Journal November 2026 updates:• Recorder integration: Record new audio or add existing recordings from Pixel Recorder, complete with playable clips and transcripts• Journal export: Export your entries and media to view offline anytime.

Original 11/10: From the “Add item” plus menu in entries, you’ll see “Record fresh audio” join the existing Take photo/video, Add photo, Health Connect activity, and location & map options.

At the moment, this audio integration is not live as Pixel Recorder also requires an revision that we’re not seeing in the Play Store yet.

Being able to add a “voice entry with audio” is a pretty common feature for journaling apps. A transcription capability looks to be available for Google’s implementation.

Sources indicate that meanwhile, in Pixel Journal settings, there’s a fresh “Export your journal” option. This creates a ZIP file of all your entries, including images. Text is exported as HTML files.

Version 2026.10.27.x of Pixel Journal is still rolling out via Google Play today.
