BOLA, BFLA, and Missing Authentication in Border-Control Web APIs: Admin Access Found in 6 Countries' Passport and Visa Systems

🌐 Source: Dev • 📅 25 Nov 2026 • ⏱️ 1 min read (119 words, ⚡ Quick Read)

  • According to recent reports, no additional hypotheses.
  • Similar API authorization design challenges apply to administrative, travel, and identity-verification systems.

Researcher Eaton Zveare discovered BOLA, BFLA, and missing authentication vulnerabilities in visa and border-control systems across six countries, including Nigeria. He verified that these flaws allow access to sensitive applicant information as well as certain approval and rejection management functions. Details are scheduled for release at a December briefing, and reports indicate that nearly all issues have been fixed as of publication.

According to recent reports, no additional hypotheses. Unconfirmed items are listed under 'Open Questions and Further Investigation'.

Similar API authorization design challenges apply to administrative, travel, and identity-verification systems. Organizations must continuously test object ID changes, role boundaries, and missing authentication tokens—including across third-party vendors—and separately audit sensitive data access and approval operations.
