Vermintide 2 mod tools get a public release, and the game's 90% off on Steam too

Though Vermintide 2's had a Steam Workshop since 2018, it's mostly used for quality-of-life stuff like UI tweaks. That's set to change now that Fatshark has announced a public release of its internal developer tools, which they say "will allow modders to work their magic on both editing and creating anything from custom levels, models, textures, particles, animations, and more!".

Right now, only a select number of sanctioned mods can be used in Vermintide 2's "official realm" which is the one with loot and leveling that carries over, while unsanctioned mods can only be accessed in a "modded realm" where there are no progression systems. Obviously that's off-putting to a lot of players, so Fatshark has announced a change.

According to recent reports, "We have an patch releasing in early December which will see the Modded Realm have its own, local, offline progression. That means that playing in the Modded Realm will still result in you gaining loot and experience, but remarked progression will not reflect on the Official Realm. This should make playing on the Modded Realm feel much better and not be discouraging for those that want to try out all of the unsanctioned mods, both the ones that already exist and the ones to come thanks to the Mod Tools!".

In a recent development, I'm not sure how many players will be happy to start over from level one just to get access to a wider variety of mods, but I hope it encourages some folks to check them out. Another thing that'll encourage latest players is that XP has been doubled from now through till Monday, and Vermintide 2 is on sale for 90% off on Steam. The DLC has been discounted too.

In less good news, the servers for Versus Mode are being turned off. "We have monitored the use of the dedicated Versus servers lately," Fatshark noted, "and come to the conclusion that they are barely used. We have therefore decided to shut these down." Versus Mode will still be playable, but via the menu option for a custom game or the lobby browser. You'll have to find a crew to play with on Discord first, which is how everyone seems to play Versus at the moment anyway.

Sources indicate that that shutdown is planned for early December, at the same time as the patch that adds local progression to the modded realm. That update will also include balance changes to buff some unpopular talents, upcoming weapon icons, and a Tome of Triumphs in the hub area that will point you at any event if there's a live one, or to the weekly event mode if there isn't. The next event planned is the annual return of Gifts of the Wolf Father in December.

Finally, Fatshark mentioned that focusing on the mod tools to get them ready for public release had to take priority from other updates. "The weapon pack and the level that we mentioned in the past has been put on hold," they wrote. "We still want to get back to that, especially the weapon pack, but for now there is no active development on that. It’s important for us that we have transparency here, and while we are not working on these things, we do stick with our games! We have aims both near and far for Vermintide 2.".
