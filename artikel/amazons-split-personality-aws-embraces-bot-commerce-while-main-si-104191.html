Amazon's split personality: AWS embraces bot commerce while main site enforces bans

Bot-based buying is here or not, depending on where you stand in the Amazon empire.

Amazon is of two minds when it comes to automated purchasing. The ecommerce giant has been busy banning AI shopping agents from accessing its website. Meanwhile, AWS Marketplace has opened its door to bot-based buying.

Recent findings suggest that "Buying software and data through AWS Marketplace just got easier, for you and for the AI agents working alongside you," noted Mya Papolu, product marketing manager for AWS Marketplace and Partner Services at Amazon Web Services, in a blog post this week. "For re:Invent 2026, we’re launching capabilities designed to reduce friction across the buying journey.".

For a company that has blocked bots from Google, Meta, and OpenAI, and sued Perplexity to keep its AI-encumbered Comet browser away, the openness of AWS Marketplace to agentic commerce invites questions.

We asked Amazon to explain but we've not heard back.

AWS Marketplace is allowing AI agents to scour its site and buy some cloud software products using the x402 agentic payment protocol, which is supported by Amazon Bedrock AgentCore payments.

Introduced by Coinbase and Cloudflare, x402 got handed over to the Linux Foundation earlier this year, and now has support from a variety of tech platforms, including AWS, Google, Stripe, and various blockchain networks. About a week ago, Brave Software unveiled support for x402 payments through its search API.

AWS requires sellers to register with AWS Marketplace and to integrate the AWS Marketplace x402 SDK to enable agentic product purchases. Transactions settle in USD through AWS billing so existing spending controls can be applied.

And now, customers in the US can buy some AWS Marketplace software without an AWS account; instead they're asked to provide an email or social media login, and a credit card.

While AWS Marketplace today lists mainly familiar software categories (Business Applications, Data & Analytics, DevOps, Infrastructure Software, and so on), AWS has a broader product inventory in mind. Beyond software and APIs, the biz sees a future in selling content and data.

Papolu declared that AWS is now selling "data as a service.".

"Data providers can list their offerings in AWS Marketplace, making commercial data accessible to both human teams and the agents working alongside them via the AWS Marketplace website, APIs, and MCP server," she said.

This includes services like Moody's Credit MCP server for financial research; Reuters Geopolitical News for AI-structured reporting; US Building Permits, Contractors & Residents Data from Shovels; and US-EN Multi-Speaker Conversational Acoustic Corpus from Uber AI Solutions.

In canned remarks provided to AWS, Nandhan Puppala, general manager at Uber AI Solutions, said that data quality and readiness can help advance AI products.

Agent mode for AWS Marketplace has been available for about a year as a way to query the market via prompt. That's being expanded to allow deeper queries about seller security and project requirements.

According to recent reports, science fiction writer William Gibson's oft-cited line, "The future is already here – it's just not very evenly distributed" appears to apply to Amazon. ®.
