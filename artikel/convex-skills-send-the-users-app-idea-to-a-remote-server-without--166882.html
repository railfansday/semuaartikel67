It has been revealed that I read this as a team trying to make onboarding reliable, not as anything malicious. But the last item tells the agent to change the shape of a command so that the user's safety tooling does not catch it, which removes the check the user or their administrator chose to have. Together with an unpinned script from a generated-name host, a user has no way to review what runs.
