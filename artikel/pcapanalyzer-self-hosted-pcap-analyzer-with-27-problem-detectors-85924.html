Versión en español: README.es.md.

Find the network fault in seconds, not hours. Upload a .pcap / .pcapng capture (gzip too) and PcapAnalyzer tells you what is failing, why, and what to check next. It runs on your own machine, so captures never leave your network.

According to recent reports, free and open source (Apache 2.0). Status: beta.

You need Docker with Docker Compose. On Windows, run the script from Git Bash or WSL.

The script creates a random access token (shown once, stored in .env) and starts the app. When the build finishes, open http://localhost:8080, paste the token into the "API token" field (top right) and upload a capture, or click "Try the sample capture".

The app listens on 127.0.0.1 only. Do not expose it on a network without an authenticated reverse proxy: the API can use your AI account. QUICKSTART.md has the details, the AI setup and troubleshooting.

You need Python 3.9+, Node 20+ and tshark (installed with Wireshark).

Sources indicate that open http://localhost:5173 and paste the same token. If tshark is not on your PATH, set TSHARK_PATH to the binary.

PcapAnalyzer is a beta. It has been tested with synthetic fixtures and public sample captures, and the most useful feedback is a capture where it misses a problem or reports one that is not real. Please open an problem at https://github.com/sebaandrada-cell/PcapAnalyzer/issues and describe the case. Do not attach captures that contain real credentials or customer data; anonymise them first or describe the pattern.

The technical reference (JSON schema, detector thresholds, limits, API errors) is in README.es.md, in Spanish.
