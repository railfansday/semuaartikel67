📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

A suspected Russian-speaking operator used an AI agent to turn security patches into working exploits with no human in the loop – a first such occurrence, according to the Google Threat Intelligence Group (GTIG) – before ultimately stealing data from victim organizations.

Google documented this attack in its fourth-quarter 2026 AI threat tracker, and said it marks a significant advance in how attackers use LLMs for fully autonomous vulnerability discovery and exploitation compared to Q3.

In this case, the threat hunters found an exposed staging server hosting a multi-agent vulnerability research and weaponization framework that integrates with multiple frontier and local models. The framework, called exploit_agent, used Russian-language tooling, and was configured to conduct continuous differential analysis of “popular web application software,” according to the report.

This includes comparing code before and after security updates, identifying potential vulnerabilities, developing exploits, and then automatically executing them without any human involvement.

The server also contained data stolen from victim organizations, and “multiple” post-compromise scripts that allowed attackers to perform nefarious activities including internal reconnaissance, brute-forcing, installing webshells, and removing other attackers’ webshells.

“Victim telemetry on the server suggests the operator was specifically interested in targeting French websites associated with the media and entertainment industries, as well as the education sector,” according to the report.

The report also documents other instances of attackers moving beyond manual LLM prompting during cyberattacks and instead deploying autonomous, multi-agent offensive security frameworks to carry out multi-stage intrusions. These include both financially motivated cybercriminals and cyber-espionage groups.

According to recent reports, in addition to the recent attacks involving the open source penetration-testing tool ARTEX, attackers have also used other AI-powered offensive frameworks, including CAIRN, CyberStrikeAI, HexStrike AI, and PentAGI. In another instance, GTIG observed attackers using PentAGI alongside proxy services to target the aerospace sector.

In a recent development, “We have observed several threat actors separately experimenting with use of these frameworks and harnesses, including financially motivated, as well as suspected espionage threat actors with a PRC nexus,” the Googlers wrote. “Given the low barrier to entry, ease of integrating new exploits, and massive scaling potential, we believe it is highly likely that threat actors will continue to use these frameworks in campaigns targeting organizations globally.” ®.
