Hi DEV, I'm Thanh, a solo developer. I build AhaBox, an Android app with 29 small brain games and 22 everyday tools (pomodoro timer, habit streaks, water reminder and so on). In the latest enhancement I added seven daily puzzles, where everyone in the world gets the same puzzle each day. Here are a few notes from building them in React Native.

Stack: Expo SDK 54, React Native 0.81, Reanimated 4, AsyncStorage for local data, Google Mobile Ads.

The easy answer is a backend that serves today's puzzle. I wanted the games to work on a plane, so the puzzle is generated on the device from the date instead.

Two things matter if you do this:.

Sources indicate that my first version used fresh Date().toISOString().slice(0, 10) as the date key. That's the UTC date. In Vietnam (UTC+7) the "daily" puzzle rolled over at 7 in the morning, so a player who solved it at 6:50 AM got a brand-new puzzle ten minutes later, and their streak logic got confused.

The fix is boring but vital: build the key from the device's local calendar.

Industry observers note that parse it back as local midnight too (new Date(y, m - 1, d)), not new Date('2026-11-25'), which is UTC midnight. Every streak, "played today" flag and habit tracker in the app now uses the same helper.

Games and tools never call the network while you play. Scores, streaks, habits and focus sessions are stored on the phone in AsyncStorage, and there's no sign-up. Ads are the only part that needs a connection, and if they fail to load, the game just carries on.

Each daily puzzle ends with a share card that shows your time and streak but not the solution, so people can post it in a group chat without spoiling it for friends.
