Samsung is officially launching its One UI 9.5 beta program today on Galaxy S26 series devices, and it’s packing some features we didn’t expect.

Ahead of today’s launch, there have been a lot of leaks around Samsung’s next major revision. But, as it turns out, there are some features here we didn’t quite know about.

Samsung details its key latest features including:.

Industry observers note that one of the biggest features here is App Lock, which has been overdue for a launch on Galaxy devices. Google added the feature in Android 17 QPR2 for Pixel phones, and it’s been very common on other Android phones, so Samsung users are finally getting in on the functionality. App Lock lets you hide an app behind added biometric/PIN unlock.

One UI 9.5 is available in beta starting today on the Galaxy S26 series in the US, UK, Germany, India, Korea, and Poland, through the Samsung Members app as per usual. A stable release is expected early next year, likely starting on the Galaxy S27 series.
