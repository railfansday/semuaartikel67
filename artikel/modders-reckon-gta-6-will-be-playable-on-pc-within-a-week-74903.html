You remember when The Legend of Zelda: Ocarina of Time Remake launched earlier this month on Nintendo Switch 2, and it was running on PC in hours? Well, modders are claiming essentially the same will be happening for Grand Theft Auto 6, a much bigger and more complicated game.

If you're wondering how these games are getting ported so promptly, it's a mixture of people dumping the game files for the public to access and, oftentimes, generative AI coding doing a lot of the grunt work of recompiling.

It has been revealed that just yesterday, Cyberleek (the hacking team or person who leaked GTA 6 files earlier this year) reportedly leaked the GTA 6 Xbox build, giving modders access to the game's release files. That's one notable part of the porting process checked off.

The only file Cyberleek notes it hasn't dropped is the main executable file, and they say they will release it when their crypto coin reaches a $15 million market cap. However, Cyberleek did say they would drop the exe file on November 23 either way. Even Cyberleek claims "this community will have it emulated inside a week, running far past 30fps".

Game modder OptiJuegos notes that GTA 6 is a GDK App, sharing its architecture with Windows and hoped for a dump of the Xbox version just a few days ago so it would run easily on PC, before Cyberleek's dump of the Xbox version.

Cybersecurity expert VX Underground took a look at the Xbox file dump and reckons it's real, and even reckons it will be playable on the 23rd if the executable file is released. Another X user notes that the dump appears to be missing the "EmbeddedXvd folders that is inside the gameos.xvd" which apparently contain system DLL files, as well as the NT kernel and drivers. Still, this is something modders can work around.
