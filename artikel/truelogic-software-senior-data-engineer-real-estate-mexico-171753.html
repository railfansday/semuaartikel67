Build and run ingestion for latest data sources, including additional MLS feeds, listing data partners, and public and private records.

Make the listings pipeline reliable: CDC that survives database failovers, freshness monitoring, and alerting when feeds lag.

Backfill three years of historical listing data into the lakehouse and build the archival access patterns that read from it.

Build raw, cleaned and modeled layers in dbt, including normalization across feeds and entity resolution for properties, agents and offices.

Add tests, data contracts and drift detection across roughly 160 listing fields, respecting each MLS’s data-use rules.

Model AI assistant conversations, product events and deal outcomes so product and leadership can measure what’s working.

Help consolidate and right-size the ClickHouse footprint for cost and performance.

Write specs before code and use AI coding tools daily to move faster.
