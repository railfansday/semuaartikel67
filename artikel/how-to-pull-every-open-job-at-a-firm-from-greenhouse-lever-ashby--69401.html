📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Most startups and a large share of tech companies host their careers page on one of a few applicant tracking systems (ATS): Greenhouse, Lever, Ashby, Workable or SmartRecruiters. Each of them publishes a public JSON job-board API meant for embedding. That means you do not need a headless browser or a proxy to get a firm's open jobs. You need the right URL.

Every system names things differently:.

If you track 50 companies you end up writing five parsers and a "which ATS is this tech giant on" detector.

I wrapped this in a small Apify actor that takes careers URLs (or greenhouse:stripe, or just stripe) and returns one flat schema:.

It has filters for title keywords, location, remote-only and "posted after", so a daily run can return only latest jobs. A run over six AI companies returned 472 engineering and research jobs in 3 seconds.

It is free right now apart from Apify platform usage, which is well under a cent per run.

Workday, iCIMS and custom career sites. Workday has no public job-board API and blocks server requests, so I left it out rather than work around it.

If your target companies use an ATS I have not covered and it has a public API, tell me which one.
