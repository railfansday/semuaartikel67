The memory market is so sketchy just now that pricing is a little all over the place; hence, we sometimes see pricing quirks like this. While you might be looking for a deal on a 32GB RAM kit, often found in 2 x 16GB configurations, buying a single stick twice can actually save you money. This Corsair Vengeance RGB RS DDR5 16GB (1x16GB) kit is $229, so you can pick up two for $458. Buying 2 x 16GB in that manner is cheaper than the same regular 2 x 16GB kit, which costs $475.

Of course, these aren't deals compared to prices a year ago, but it seems we're a long way from prices returning to that point. If you're also looking for a motherboard and/or CPU, you can generally save more on memory by picking up a RAM bundle. Sources indicate that get a single stick of Corsair Vengeance RGB RS DDR5 RAM with CL38 CAS latency and addressable RGB lighting, available in both black and white. Buying two of these is cheaper than buying a 2 x 16GB kit of the same model.

Corsair's RS line is a slightly budget version of its famed Vengeance line, but this is still very solid RAM, with 6000 speeds for the AMD gaming sweet spot. This memory supports both AMD EXPO and Intel XMP 3.0 for one-click optimization, so it will work seamlessly on either platform. As noted, the key selling point here is that this RAM is cheaper to buy as individual sticks of 16GB, rather than as a set of two.
