It’s been a wild ride for Google Pixel’s App Lock feature, but the company is officially re-releasing the feature today, right alongside its debut on Samsung Galaxy devices.

App Lock debuted on Google Pixel in an August build of Android 17 QPR2’s beta. The feature lets users hide apps behind a biometric or PIN authentication layer while also hiding notifications, widgets, and data from AI services. It’s a useful privacy features, but one that Google removed in subsequent updates. The feature later returned in QPR3 Beta 3 last month, and today Google is officially re-releasing it.

The feature is still only in Android 17 QPR3 Beta 3 for Google Pixel devices, an update that should be released to the stable track in early 2027.

You can still access App Lock by long-pressing on an app icon and adding it to the app lock list.

In a post on Reddit, Google’s Community Engagement Manager details that App Lock on Google Pixel was removed for improvements before getting a full release:.

…the product team decided to temporarily pull back the feature from the QPR2 Beta to allow for additional polish, thorough testing, and robust integration across all system surfaces.

In a recent development, that’s why Samsung’s One UI 9.5 beta release today also brings support for App Lock. The feature is built into Android 17 QPR2, seemingly the release that One UI 9.5 is based on, but Google Pixel devices aren’t getting it until QPR3. As far as release timelines go, this means that Samsung’s Galaxy S27 series will probably ship with this feature out of the box, where Pixel phones won’t get it until around March or so. One UI 9.5 won’t roll out for older Galaxy devices until May, if One UI 8.5 serves as an example.
