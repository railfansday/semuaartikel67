Agentic offensive framework automates familiar attack techniques, with weak defenses potentially breached in minutes.

Chinese and North Korean state-sponsored hacking crews are among the growing number of groups known for using the ARTEX pentesting tool in attacks, Microsoft said this week.

ARTEX is an open source, AI-powered penetration testing framework that attackers have adopted to automate reconnaissance, credential attacks, and exploitation since its public release in July.Campaigns that have been linked to ARTEX have targeted cloud environments, IT software like ConnectWise, and financial institutions globally, sometimes reaching privileged access in under three hours.

Salt Typhoon is arguably the most recognizable name on the list of ARTEX beneficiaries – the group responsible for attacks on telcos AT&T and Verizon, US government systems, UK prime minister's aides, and more.

The lesser-known Crystal Typhoon – the group behind the ArcaneDoor attacks back when Microsoft called it Storm-1849 – was also named alongside it, as were North Korea's Onyx Sleet and Pearl Sleet.

Microsoft also named China-state-aligned Storm-0940, linked to the ConnectWise compromise, and financially motivated, Cambodia-based Storm-3358. It had previously reported both groups' use of ARTEX.

Chinese cybersecurity organization ThreatBook claimed ownership of ARTEX in November. GitHub user "Autumn-27" originally published its source code with a Chinese-language interface in July.

Various forks of the repo, which was taken down in October, have meant that the same framework is available in multiple languages.

According to Infrawatch, there are more than 130 variants of ARTEX in circulation, and it is the most widely used agentic offensive framework (AOF) at present.

Like other offensive security tools adopted by criminals, ARTEX can lower the effort required to mount attacks. Experienced groups can also use it to automate repetitive work and pursue multiple avenues at once.

As Microsoft echoed this week, after the FBI and AWS issued their warnings earlier this month, ARTEX is proving to be a useful tool for the more sophisticated groups to streamline and hasten their attacks too.

It's being used to help attackers steal AI and cloud credentials at "industrial scale," as AWS put it, which provide attackers access to advanced models for free.

Microsoft says ARTEX can progress from reconnaissance to persistent, privileged access within minutes, depending on its configuration and the target's defenses.

"In the past few weeks, we've reported several distinct campaigns that abused ARTEX to search public repositories for exposed secrets, enable supply chain compromise, and scan internet-facing systems for exploitation," its threat intelligence team blogged. "These campaigns illustrate how threat actors use ARTEX to automate various stages of the attack chain.

"Threat actors define scope and targets for ARTEX, which then uses AI agents to set verifiable goals, define tactical steps for each stage of the operation, use tools to attack targets, create graphs to track discovered systems and results of actions, and report back to the threat actor.".

Notably, ARTEX does not offer any fresh attack techniques. All of the tool's capabilities were previously known to the cybersecurity world, but its value lies in the automation capabilities it offers users, chaining attacks at machine speed.

In the UK NCSC's warning about AOFs this week, it said the key strengths of this technology are its speed, its thoroughness in probing target systems for weaknesses, how it learns from failures instantly, and that it is inexpensive to run at scale.

According to recent reports, AOFs' speed comes at a cost, however. These tools are noisy, the NCSC said, making them easier to detect in network logs and by defensive solutions.

According to recent reports, some examples of the attacks in which the tool has been implicated include Storm-0940's hit on ConnectWise, which enabled attempted sign-ins to more than 2,250 Microsoft 365 tenants, various financial institutions in South Korea and India, UK registrar 123 Reg, and the European Commission. ®.
