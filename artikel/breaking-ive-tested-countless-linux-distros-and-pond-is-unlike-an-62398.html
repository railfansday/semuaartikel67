Linux is all about choice. From the kernel all the way up to the desktop environment, you get to determine what is used and even how it is used. The staggering number of distributions, desktops, package managers, file managers, and terminal apps provide you with a nearly infinite combination of choices. That choice is and has always been a key aspect of Linux.

It has been revealed that so too is innovation. If there’s one thing that separates Linux from all other operating systems, it’s the willingness to try something different. Linux developers are always pushing the limits of what an operating system is, and this latest take on the OS is the epitome of that.

In a recent development, the distribution in question is called Pond. According to the developers, “Pond is an opportunity for us to play with familiar conventions and experiment with fresh ideas that make a computer more natural and satisfying.”.

The developers have achieved something special. Pond takes the standard UI and turns it on its head. Part tiling window manager, part mobile UI, part GNOME, and part something we’ve never before seen, this desktop environment is special. It took me all of five minutes to fall in love with what they’ve created.

Sources indicate that if you’ve ever considered using a tiling window manager, but thought the lack of a mouse made it seem a bit too complicated, Pond is exactly what you want. Here’s how it works:.

In a recent development, pond uses the Niri window manager to arrange windows in columns along an infinite strip from left to right. In multi-monitor setups, each display gets its own strip, so windows never “overflow” from one monitor to the next.

According to recent reports, at the same time, workspaces are dynamic, and there’s always a latest workspace automatically created to the right of the farthest-right window. The combination of the Pond sidebar and Niri’s way of handling windows makes this UI truly original.

Pond doesn’t have a traditional desktop menu. Instead, you open the launcher (using the Super+Space key combination), type the name of the app you want to install, and hit Enter when the app name appears on both the display and as an icon in the top portion of the sidebar.

Another thing that sets Pond apart is how you install apps. Yes, you can open a terminal window and install an app using the pacman command, or you can open the launcher, type install, press Enter, and then type the name of the app you want to install. Once you hit Enter a second time, the installation will begin. Many apps install via Flatpak, but on the off-chance an app must be installed via the pacman package manager, you’ll be prompted to type your user password before the installation begins.

As I hinted earlier, Pond is based on Arch Linux, which means it’s a rolling-release distribution. One matter that did give me pause was the lack of a GUI update system, which indicates that updates would have to happen in the terminal, like so:.

In a recent development, I installed the Shelly GUI frontend, which does have an update component. Personally, I would simply open the terminal window, type sudo pacman -Syu, hit Enter, and let the update run in the background. But if a GUI is your jam, Shelly is what you want.

It has been revealed that it would be sweet if the developers allowed updating the system from within the launcher, so it didn’t require opening the terminal first. The Pond launcher does allow running system commands from the launcher, which will then open the terminal window and execute the command. For instance, open the terminal, type a command, hit Enter, and then scroll through the list of available commands that can be run.

Pond ships with kernel 7.3.4-3, so it has outstanding hardware recognition and performance.

In a recent development, you should definitely give Pond a try, especially if you’re adventurous and want to experience something completely different. If, on the other hand, different is not in your stream, then Pond will frustrate you to no end.
