📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Last week, Google declared that Gemini tasks (previously called Spark) is now available to free consumers in the US, along with an integration in Google Messages. In testing, I’ve found this instance of Gemini to be proactive and feel more like an assistant than the Gemini app does.

According to recent reports, the original Gemini integration in Google Messages dates back to 2024 with a dedicated FAB (floating action button) above Start chat. It lets you have a straightforward conversation with Gemini.

This updated experience makes use of the “Channels” feature introduced last week that allows you to Text or Email with Gemini to accomplish tasks.

With the latest Google Messages beta (version 20261120_01_RC00), we’re seeing the Gemini FAB (or top-right corner icon with the homepage redesign) open gemini.google.com/channels on a fresh install. If you’ve already set up the new integration, the shortcut takes you to the new chat, which uses RCS Business Messaging behind the scenes.

According to recent reports, after using it for the past few days, the proactive nature of Gemini tasks in Google Messages has really stood out. Every morning, Gemini messages me about what’s on my schedule or what should be on my radar. Examples include:.

It has been revealed that while this instance of Gemini is ostensibly for tasks, I’ve been able to ask general knowledge questions, like about the weather, similar to the old experience. Additionally, you can upload attachments like images and files.

This new Google Messages integration is right now available in the US and requires that you have tasks enabled in the Gemini app.
