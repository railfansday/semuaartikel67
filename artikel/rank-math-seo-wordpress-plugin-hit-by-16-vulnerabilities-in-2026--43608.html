📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Sixteen vulnerabilities have been discovered in the popular Rank Math SEO plugin in 2026, setting a fresh record for vulnerabilities discovered, more than any other SEO plugin.

Rank Math’s 2026 vulnerabilities included potential pathways to website takeover, exposure of protected information, and unauthorized changes to WordPress content and data. All of these things could also have a negative impact on SEO.

Recent findings suggest that although AI is making vulnerability disclosures more common, other SEO plugins like Yoast SEO did not have anywhere near that many vulnerability discoveries. The free version of Yoast SEO was reported by Wordfence to have a total of four vulnerabilities in 2026 and only two were discovered in the paid version.

The sixteen vulnerabilities share certain challenges in common but arguably the worst of them are:.

Remote Code Execution (CVSS rated 8.8) Two vulnerabilities with a CVSS severity score of 8.8 were discovered that could enable attackers with Contributor or Author-level access to execute arbitrary code on the server, potentially leading to complete website compromise.

Arbitrary File Upload (7.2) One of the vulnerabilities could potentially lead to a website takeover through malicious file uploads, although this vulnerability required Administrator privileges. CVE-2026-104752: Arbitrary File Upload, requiring Administrator-level access or higher. Disclosed October 8, 2026. CVSS 7.2 (High).

It has been revealed that stored Cross-Site Scripting (7.2) An unauthenticated attacker could potentially execute malicious JavaScript in an Administrator’s browser. Depending on the circumstances, that could lead to privileged actions or account compromise. CVE-2026-66702: Stored Cross-Site Scripting, requiring no authentication. Disclosed July 31, 2026. CVSS 7.2 (High).

It has been revealed that stored Cross-Site Scripting (7.2) An unauthenticated attacker could potentially execute malicious JavaScript in an Administrator’s browser. Depending on the circumstances, this could enable an attacker to make unauthorized changes to the website or take control of an Administrator’s account. CVE-2026-66702: Stored Cross-Site Scripting, requiring no authentication. Disclosed July 31, 2026. CVSS 7.2 (High).

In a recent development, these vulnerabilities could allow attackers to access protected content or sensitive website information without the necessary permissions. Unlike vulnerabilities that enable unauthorized changes, these primarily concern exposing information that should remain restricted, although SQL injection could also allow attackers to manipulate website data.

These vulnerabilities could enable attackers to make unauthorized changes to a WordPress website, including modifying content-related data, changing homepage settings, and deleting SEO information. Some could be exploited without logging in, while others required an account but allowed actions beyond that user level’s permissions.

Most vulnerabilities were discovered within a relatively short period. Eleven of the 16 vulnerabilities were discovered between August 27 and October 14, 2026. Of those vulnerabilities, late August and early September saw a concentrated cluster of vulnerability discoveries. Eight were reported between August 27 and September 3, within just eight days.

In a recent development, the disclosures continued into October. Five vulnerabilities were reported in October, including three disclosed on October 8 and the latest on October 27.

As previously stated, Rank Math’s direct competitor, Yoast SEO, only experienced four vulnerabilities during a year which saw an increase in vulnerability discoveries. The unusually high number of vulnerabilities leads to questions about Rank Math’s coding practices, code review, and quality control.

The other issue in the sixteen vulnerabilities is that are repeated instances of the same kinds of exploits.

In a recent development, missing authorization was the most frequently identified vulnerability category. Seven of the 16 entries explicitly mention inadequate permission checks, pointing to recurring problems with enforcing permissions before allowing actions.

Some security problems could lead to complete website compromise. Two vulnerabilities carried CVSS scores of 8.8 and involved remote code execution, allowing attackers who met the required conditions to potentially execute malicious code on the server.

Overall, the vulnerabilities involved a broad range of security weaknesses. They included unauthorized modifications, information exposure, cross-site scripting, SQL injection, arbitrary file uploads, and remote code execution. The vulnerability discoveries do not point to just one type of coding lapse; they point to a wide range of coding issues.

The full list of Rank Math vulnerabilities can be found at Wordfence, with links to a description page for each vulnerability.
