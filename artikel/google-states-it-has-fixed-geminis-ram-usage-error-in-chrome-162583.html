Google has fixed an issue that caused excessive RAM use by Gemini for Chrome users.

Sources indicate that AI tools are infamous for RAM use, but that’s generally not on your local machine. A bug with Gemini, though, left some Chrome owners noticing that the tool was eating up several gigabytes of memory unexpectedly.

Google, in a comment, says this issue has been fixed:.

This has now been resolved, so please let us know if you are still experiencing any issues with high memory usage in Chrome.

Typically speaking, Gemini’s web app shouldn’t be using more than a few hundred megabytes of memory at any given time, maybe around 1GB if you’re on a particularly long chat session. But some customers were reporting upwards of 5GB or more in what was clearly an error.
