Metano Raises $12M Seed to Secure AI Agents Across the Enterprise

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

Metano announced its emergence from stealth on November 19, 2026, with a generally available security and governance platform for enterprise AI agents and $12 million in seed funding led by Sierra Ventures.

It has been revealed that correlation Ventures, High Alpha and 360 ONE also participated in the round. Co-founder and CEO Neelima Rustagi previously held product roles at ServiceNow, Zscaler, Palo Alto Networks and Demisto, while co-founder and CTO Ratnesh Pandey worked on endpoint security at FireEye, Bromium and McAfee, according to the founders’ biographies.

Industry observers note that metano is targeting the gap between an agent’s privileges and its behavior. Agents can act with legitimate credentials and approved tools while changing what they do in response to instructions, external content and operating conditions. An action’s apparent legitimacy therefore does not establish that it matches the agent’s purpose.

The platform inventories approved and unapproved agents, MCP servers, skills and software packages, along with their access privileges and potential exposures. Coverage extends across endpoints, homegrown agents, cloud platforms and SaaS environments, and can include the models, plugins, tools and human and non-human identities associated with each agent.

Recent findings suggest that metano says Hive, its real-time context graph, connects tasks, identities, tools, data access and actions across an entire session. The aim is to identify suspicious activity by examining whether a sequence of actions aligns with what the agent was built to do, while giving security teams a correlated record of endpoint, network and identity activity.

Those signals feed centrally managed guardrails that operate where agents run, including activity that may bypass network gateways. Rustagi connected that design to the limits of earlier security tools: “Traditional security tools weren’t designed for AI agents that can make decisions and change their behavior as they operate.”.

Industry observers note that MARS Labs, Metano’s research group, investigates malicious agent skills, compromised software dependencies and vulnerabilities in MCP connections. That research informs the platform’s detection work, extending the security focus beyond an agent’s live actions to the components and connections from which it is built.

Sources indicate that the product documentation claims controls can be generated from a developer-supplied agent specification. If no specification exists, Metano baselines the agent’s real behavior for about a week before writing controls. New controls initially ship in audit mode, and the security team decides individually when each one moves to enforcement.

Discovery, detection and monitoring require no code changes across the supported surfaces. Full inline enforcement for homegrown agents, however, requires one line of Metano’s SDK at agent initialization. That distinction separates initial visibility from the developer work needed for complete enforcement.

Deployment options include Metano on-premises or inside a customer’s own AWS, Azure or GCP account, with collected data remaining on infrastructure controlled by the customer. The platform is designed to feed Splunk or another SIEM using OCSF and standard schemas, and to run alongside existing security tools without reconfiguring them.

Sources indicate that metano notes security teams can begin using the platform in less than 30 minutes. A free Eval Edition provides 30 days of real-time scanning for agent activity, risky configurations and potential exposure. Its detections map to MITRE ATLAS and the OWASP Top 10 for Agentic Applications.

Sigmoid CISO Srivatsa Ramarao stated the platform had affected his tech giant’s adoption of AI: “Metano has empowered us to securely adopt AI while minimizing shadow risks, preventing sensitive data leakage and strengthening our protection of enterprise information.”.

The launch makes session-level intent the center of Metano’s security model. Its rollout terms also define the practical trade-off: organizations can begin with discovery and monitoring without changing agent code, but full inline control of homegrown agents requires developer participation and a deliberate move from audit mode to enforcement.
