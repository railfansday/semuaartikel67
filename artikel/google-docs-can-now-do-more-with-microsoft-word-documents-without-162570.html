Google Docs is getting an update in how it handles Microsoft Word documents, adding the ability to compare revisions without converting the file.

You can already upload a Microsoft Word document (.docx) to Google Drive and use it within Docs without converting the file, but there are some limits. One of those was comparing documents, which Google is now fixing with an update.

It has been revealed that rolling out now, Google Docs can now directly compare two documents, even if one is in a Microsoft Word format. To do this, you’ll need to upload the Word document to Drive, then select it in the “compare documents” tool, with Docs then showing any differences between the two. There are plenty of scenarios where this is useful, including when comparing versions of a contract.

This latest feature is enabled for all users, and the tech giant is apparently looking at similar functionality for PowerPoint files too.
