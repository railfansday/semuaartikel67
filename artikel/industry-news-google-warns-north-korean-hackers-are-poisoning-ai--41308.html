State-backed hackers are using fake recruiters and tampered Claude Code settings to breach crypto networks.

Cyberattacks against the cryptocurrency industry have crossed a dangerous threshold as threat actors shift from basic AI prompts to autonomous AI agents capable of running intrusions from start to finish.

According to the Google Threat Intelligence Group (GTIG) and Mandiant report, state-backed hackers are actively targeting crypto firms in North America and Europe by turning popular AI developer tools into malware delivery traps.

It has been revealed that researchers have linked a suspected North Korean hacking campaign to attacks on cryptocurrency companies. The group, known as Midnight Neptune, uses fake recruiter profiles and tampered software settings to break into company networks.

The attackers approach targets on professional networking platforms, posing as recruiters with AI-generated profile photos.

Industry observers note that they then invite victims to fake online meetings, where simulated audio or video problems prompt them to run scripts to fix the issue. This social engineering trick, known as ClickFix, gets victims to execute malicious commands themselves.

Once inside a company’s network, the attackers tamper with its internal code repositories, modifying the configuration file used by Anthropic’s Claude Code.

The next time a developer debuts Claude Code, the altered settings silently download a backdoor called SOMBERMEME.

The attackers also create GitHub Personal Access Tokens disguised as Microsoft Copilot to make their activity look like normal developer traffic.

The report also revealed a major advance in automated hacking that puts open-source Web3 infrastructure at risk.

Google researchers discovered an active tool called exploit_agent on an exposed testing server. It uses large language models (LLMs) to compare software code before and after security updates, identify newly patched vulnerabilities, write code to exploit them, and launch attacks — all without human involvement.

It has been revealed that that puts open-source protocols at risk. Since code updates are publicly available, hackers can spot newly fixed vulnerabilities and exploit them before operators have a chance to install the patches. Even a brief delay can leave networks vulnerable.

Google Threat Intelligence Group (GTIG) reported that disclosed vulnerabilities and exploits nearly doubled between January and August 2026.

Exploited zero-day vulnerabilities also rose from an average of eight per month in 2025 to 11 in 2026, reaching 22 in August alone.

Beyond traditional cyberattacks, Mandiant warns of a growing threat called LLMJacking. Criminals hijack corporate cloud accounts, steal AI computing power, and resell it through underground marketplaces known as LLM Mixers. The resulting fraud can exceed $100,000 in a single day and reach $1 million per victim.

Meanwhile, influence networks use more than 100,000 fake social media accounts to spread misinformation, fuel token hype, and trigger artificial market panic.

To counter these threats, Google is deploying AI security tools such as Major Sleep and CodeMender to find and fix software vulnerabilities before hackers exploit them.

The GTIG report highlights several security risks for the crypto industry.

Companies using AI coding tools should check their code repositories for unauthorized commands and keep third-party access tokens secure.

They also need to install software updates swiftly, as AI-powered hackers can turn newly discovered vulnerabilities into working attacks.

Employees should never follow unexpected browser or video-call instructions asking them to copy and run computer commands.

Investors, meanwhile, should be cautious of sudden waves of online hype or panic, which fake social media accounts can create at scale.
