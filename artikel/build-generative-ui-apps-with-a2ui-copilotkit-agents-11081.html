Agent-User Interactions are now evolving from text exchanges to rich UIs. Until recently, most conversations looked like this:.

User: "Find me a holiday package to Bali in March." Agent: (six packages in prose, each with dates, hotel, flights, price) User: "The five-night one with breakfast." Agent: "Here's the link. You can book it on the operator's site.".

Agents could blueprint the trip, but everything came back as walls of text. They had no standard way to render a selectable list of packages, a map of the destinations, or a date picker to carry you through the rest of the booking, inside the conversation itself.

Industry observers note that generative UI is the layer that lets agents build interfaces at runtime, shaped by what each request needs - giving users a rich, interactive experience. Implementing that takes two pieces: a way to describe the UI and an agentic stack that connects your agent to your application and renders that UI.
