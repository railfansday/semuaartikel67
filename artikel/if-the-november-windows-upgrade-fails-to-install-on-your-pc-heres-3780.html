If the November Windows upgrade fails to install on your PC, here’s what to do

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

In a recent development, ah, Microsoft. Another Windows patch, another glitch. This latest one affects some Windows 11 users who attempt to install this week’s November Patch Tuesday update, only for it to fail. But don’t worry, there’s already a fix in play.

Also: You can now restore Windows 11 even if it can’t boot up – here’s how.

On its support page to the November enhancement designated KB5132061, Microsoft revealed and explained this latest problem.

Windows consumers who installed the November preview upgrade released on October 28 may run into a glitch when trying to install the actual November update released on November 10. In this case, the installation may fail to complete. Your PC might repeatedly try to install the update or you may simply see an error code such as 0x80070306, 0x800f0989, or 0x800f0993.

I can confirm the problem. I installed the preview revision on one of my Windows 11 virtual machines. Trying to then install the actual November update triggered the installation error.

If you’re in the same boat, what can you do to fix this dilemma? Just be patient.

Also: Windows finally gets a built-in internet speed test tool – how to try it.

Microsoft promises that all affected PCs should receive repairs within 24 to 48 hours starting from November 11, 1pm ET. For this, make sure your PC is connected to the internet and is set up to receive updates via Windows Upgrade. Head to Settings and select Windows Update. You may already find the November update known as 2026-11 Security Update (KB5132061) (26300.9974) available again. If so, select it to install it, and the process should work now.

Sources indicate that I tried this on my virtual machine, and the November patch installed without a hitch. But if you still bump into errors, check out Microsoft’s support page on troubleshooting problems updating Windows.

Here’s how the update process works.

Microsoft typically releases each monthly Windows patch in two phases.

According to recent reports, first, there’s an optional preview enhancement that kicks off around the end of the previous month. This one is considered a non-security update because it contains only feature changes. In this case, the preview update for November was released on October 28. Labeled KB5127936, this one unveiled the fresh customizable right-click menu, Cloud rebuild option, and other feature changes.

Also: You can change Windows settings directly from a search now.

Second, there’s the actual mandatory Patch Tuesday update that contains both security patches and the non-security changes. Here, the November KB5132061 update was rolled out on November 10.

Recent findings suggest that the preview updates are designed for IT administrators, software testers, and others who want an early look. That means they aren’t always fully baked and may contain a few bugs. But since they pop up in Windows Revision, anyone can install them.

According to recent reports, the actual Patch Tuesday updates are for all Windows customers. In this case, there seemed to be an incompatibility or other conflict between the two updates that Microsoft then had to resolve.
