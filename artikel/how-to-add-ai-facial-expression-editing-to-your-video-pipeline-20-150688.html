It has been revealed that performance transfer is great for animation, but someone has to record a upcoming take for every change. If your promise is “fix the reaction in the footage you already have,” direct editing fits better.

Industry observers note that DRAMA is an AI facial changer from SyncMonster. In the web app, users upload a video or image (MP4, MOV, JPG, PNG), pick a face, choose an emotion, and set intensity on a slider from subtle to strong. The app offers four core emotions (Happy, Sad, Angry, Excited) plus presets such as Surprised, Serious, Evil and Intimidating, with the extra presets on paid aims. It supports emotion blending and editing one face in a group shot without touching the others. SyncMonster states that edits keep the original resolution, lighting and details such as glasses and beards, which is a vendor claim you should test on your own footage.

Runway exposes Act-Two through its developer API as the character_performance endpoint. You send a character (image or video) and a driving performance video, and Act-Two transfers facial expression, and optionally body and hand motion, onto the character. Output is 24fps.

In a recent development, runway’s API pricing guide lists Act-Two at 5 credits per second of output, with credits priced at $0.01 each, so $0.05 per second. Earlier documentation mentioned a 15-credit minimum per generation, and the current pricing page does not list one, so check for minimums before you budget short clips. The documentation also exposes an expression intensity setting to control how strongly the performance is applied.

The catch is the input requirement: every edit needs someone to act the latest reaction. That suits character animation, but it is a heavy ask for a user who wants a slightly warmer smile in an interview clip. It also drives one character per generation.

According to recent reports, livePortrait is an open-source portrait animation framework from Kuaishou’s KwaiVGI group. It animates a source image or video using a driving video or a saved motion template, supports video-to-video portrait editing, and offers retargeting controls for eyes and lips.
