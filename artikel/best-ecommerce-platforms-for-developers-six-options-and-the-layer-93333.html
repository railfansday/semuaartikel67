According to recent reports, picking an ecommerce platform is really a decision about which layers you want to own: the storefront, the catalog and order logic, the payment flow, and the hosting underneath. Every platform below draws that line in a different place. If you have already settled the front-end question with a comparison like SitePoint's Astro vs Next.js guide, the next question is what sits behind it. Prices are from each vendor's pricing page as of November 2026.

In a recent development, shopify is the fully managed option. Basic costs $29 a month with card rates from 2.9% plus 30 cents, and a 2% fee applies to orders processed through a third-party gateway on that plan. Developers get two routes: Liquid themes, or Hydrogen, Shopify's headless toolkit, where your framework owns routing and rendering and Hydrogen supplies the Storefront API client and cart. Templates exist for React Router on Oxygen and for Next.js on Vercel. Plus starts at $2,300 a month.

It has been revealed that whop is a business platform for taking payments and sending payouts, and it sits under a storefront you have already built rather than replacing it. The Checkout element runs in the browser with no server code and no API key on the page. You pass your own order ID as metadata, Whop copies it onto the payment, and your server fulfills from a signed webhook that follows the Standard Webhooks spec. Domestic cards cost 2.7% plus 30 cents with no monthly fee, buyers see payment methods chosen by their location across 195 countries, and the same balance pays out in over 200 countries, including to affiliates or sellers you onboard. Whop's own guide highlights how to integrate a checkout API into a Next.js storefront end to end. The trade-off is that there is no catalog or shipping engine; you collect address fields at checkout and trigger fulfillment from the webhook.

WooCommerce is a free plugin on WordPress you host yourself, so you own updates, security, and performance. Its payment gateway, WooPayments, charges US merchants 2.9% plus 30 cents per card transaction, 1.5% more for international cards, 2% for currency conversion, and $25 per dispute. Everything is PHP hooks and filters, which makes it the natural pick for agencies already living in WordPress and the wrong pick for anyone who does not want to run a server.

BigCommerce hosts the back end and lets you bring any front end. Core is $29 a month billed annually, capped at $30,000 in trailing annual sales, and plans auto-upgrade as volume grows. There are no platform fees when you use an embedded payment provider, and a 2% fee on Core if you use another one. Catalyst, its reference storefront, is built on Next.js, React Server Components, and the Storefront GraphQL API, and deploys to Vercel.

In a recent development, medusa is an open-source commerce framework in Node.js and TypeScript, with an MIT-licensed core and a commercial enterprise edition. SitePoint covered it when it was still a young Shopify alternative; it now has over 37,000 GitHub stars. Self-hosting is free. Medusa Cloud starts at $29 a month for development, $99 for launch, and $299 for scale, with no percentage of sales, and the firm claims you can export your data and self-host at any point.

Saleor is a GraphQL-native, API-only commerce platform written in Python and released under the BSD-3 license. Self-hosting is free. Saleor Cloud starts at $1,599 a month for up to $200,000 in monthly sales, with 0.8% on orders above that, and $3,999 a month at the next tier. It is built for teams with a dedicated engineering function and a large catalog, which is exactly who should pay that price.

It has been revealed that own only the storefront, and Shopify or BigCommerce will carry the rest. Own everything, and Medusa or Saleor give you a back end you can read. Already on WordPress, and WooCommerce is the obvious fit. Already have a storefront in Next.js or Astro and only need the money to move, and Whop is the shortest path. Whichever you pick, the checkout is where disputes start, so log what SitePoint's friendly fraud guide for developers recommends from day one.
