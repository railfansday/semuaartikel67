Latest Update: Developer vibe codes Windows 11 alternative operating system for amd64, arm64, and riscv64 hardware

📑 Quick Jump: 1. Overview • 2. Key Details • 3. Closing Notes

There’s a upcoming vibe-coded OS in town going by the name of LiberNT. Its name provides a big clue to its nature: Liber (free), NT (New Technology architecture, as in Windows NT). As it has been released under GNU’s GPL3.0 license, LiberNT also provides a free new way to run apps designed for Microsoft’s Windows 11.

Industry observers note that liberNT has been under development for some time, but on Wednesday it made a massive leap. Reading the intro, you might have wondered if this work had a ReactOS connection, and indeed there is. But what started as a fork of ReactOS has already got a latest boot loader, graphics stack, memory manager – and yesterday a new kernel. “LiberNT is not affiliated with or endorsed by the ReactOS project or Microsoft,” insist the devs behind this OS.

Industry observers note that this still fledgling operating system is designed (mostly) for modern hardware and focuses on 64-bit platforms: amd64, arm64 and riscv64. Ambitiously, the goal is to develop this OS to deliver a free Windows alternative that is “stable, reliable and efficient.” On that latter point, yesterday’s blog revision relays some impressive efficiency and performance stats.

According to recent reports, the LiberNT team has benchmarked their eponymous OS against Microsoft’s Windows NT, and it beats it hands-down in 112 of 132 system tests. The testing assessed performance in the following areas: file caching, memory handling, threads and locks, plus FAT32 and NTFS storage. Interestingly, both the free and commercial OS were benchmarked on a Mac with an Apple M3 Pro chip. We scanned through the results, and the worst loss for LiberNT was a 28% performance deficit vs Win11, but it claims some astounding relative performance wins showing the free OS being over 2000% faster.

In a recent development, the devs are entirely clear about the fact that the operating system was vibe coded. “AI is part of how LiberNT is built. It helps us review and write code, and everything it writes is then reviewed by a human,” explains a section of the GitHub page for the project. “Before anything reaches the main branch, a person runs and validates the end-to-end tests. We care about this project too much to let a regression slip through.”.

Industry observers note that if the above highlights about this fresh OS's scope, mission, compatibility, and performance have whetted your appetite, there is the full code available via the GitHub link (top), and even some ready-made builds as bootable disk images. Indeed, I’m quite eager to give this new OS a spin. Hopefully, it works as well as the ambitious developers suggest, and I won’t be disappointed by any stability challenges using my daily productivity apps like Firefox, Word, and an old release of Photoshop.
