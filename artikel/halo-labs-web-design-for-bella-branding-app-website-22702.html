Sources indicate that bella Branding, App & Website by Halo Lab is a web design project. See how Halo Lab built branding, an app, admin panel and website for Bella.

Bella Branding, App & Website Design for AI EdTech by Halo Lab solves a tough operational constraint: the software must control a physical robot in real time, function offline for schools with limited connectivity, and serve two audiences at once. Kids train the social robot directly, while teachers build lessons behind the scenes. It's a tricky split to balance on a single platform. In the first image, the mobile app video call screen rests against a coral armchair, pairing live camera feeds with floating movement and video flow tags so a child doesn't need to read code.

Instead of hiding machine learning behind abstract menus, Halo Lab structured the learning flow around interactive flashcards and a visual block editor. When a block needs a upcoming skill like finding an apple, the child shows an object or records a sound, watching a live confidence feedback bar climb with each example. You can see how the web design and dashboard system adapts for adults in the fourth and fifth images. On the laptop screens, the flashcards dashboard and admin panel trade playful action tags for a clean layout and filled icons in neutral tones, letting teachers and parents create flashcards, assign homework, and manage school robots.

It has been revealed that the sixth image demonstrates how those adult-assigned modules land back on the smartphone inside the Video Explorer lesson list, photographed next to branded denim to bridge the screen interface with tactile classroom materials.
